## Qué ha cambiado {#what-changed}

| Nombre anterior en la documentación de Base | Nombre en Coinbase Developer Platform | Qué hacer                                                                                                          |
| ------------------------------------------- | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Base Account SDK                            | Coinbase Wallet SDK                   | Consulta la [documentación de Coinbase Wallet SDK](https://docs.cdp.coinbase.com/coinbase-wallet/overview).        |
| Base MCP                                    | Wallet MCP                            | Consulta la [documentación de Wallet MCP](https://docs.cdp.coinbase.com/ai-agents/coinbase-for-agents/wallet-mcp). |
