Base Verify permite que los usuarios demuestren que controlan cuentas verificadas sin exponer sus credenciales a tu aplicación. Úsalo para añadir resistencia a ataques Sybil, evitar que una misma persona participe varias veces con distintas billeteras y restringir acciones en función de atributos verificados.

## Diferencias entre las integraciones {#how-the-integrations-differ}

|                          | Verificar cuentas sociales                                                                                    | Verificar usuarios onchain                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Aplicación de las reglas | El backend de tu aplicación                                                                               | Tu contrato inteligente                                                                        |
| Componentes de Base      | API REST de Base Verify                                                                                   | API REST de Base Verify y contratos onchain                                                    |
| Resultado                | Token de verificación y atributos                                                                         | `identityHash` firmado, vencimiento y firma                                                    |
| Ideal para               | Experiencias de aplicación con acceso restringido, recompensas y reclamaciones controladas por el backend | Reclamaciones a nivel de contrato, depósitos, acuñaciones, votaciones y otras acciones onchain |
| Backend de la aplicación | Obligatorio                                                                                               | No es necesario en el momento de la reclamación                                                |

Ambas integraciones utilizan un mensaje SIWE firmado con la billetera para demostrar que el solicitante la controla. Base Verify evalúa el proveedor o la política solicitados y devuelve únicamente los datos de verificación necesarios para el flujo seleccionado.
