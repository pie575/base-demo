## ¿Qué interfaz necesito? {#which-surface-do-i-need}

| Quieres…                                                                   | Usa                                                                                      |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Verificar la titularidad de una cuenta o aplicar una política de identidad | [Base Verify API](/es/sdks/base-verify/overview)                                            |
| Compilar y probar contratos nativos de Base en local                       | [CLI de base-anvil](/es/sdks/base-anvil)                                                    |
| Leer saldos, bloques o registros, o enviar transacciones sin procesar      | [JSON-RPC de Ethereum](/es/base-chain/api-reference/rpc-overview)                           |
| Recibir en streaming confirmaciones en menos de un segundo                 | [API de Flashblocks](/es/base-chain/api-reference/flashblocks-api/flashblocks-api-overview) |
| Rastrear una transacción o un bloque                                       | [API de depuración](/es/base-chain/api-reference/debug-api/debug_traceTransaction)          |
