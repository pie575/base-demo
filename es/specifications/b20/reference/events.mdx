*Lista exhaustiva de los eventos emitidos por el sistema B20, agrupados por el archivo en el que se declaran.*

## [`IB20`](/specifications/b20/reference/interfaces/ib20) {#ib20}

| Evento                                                                                                    | Emitido por                                                                                                                                            | Cuándo                                                                                                                                                                       |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Transfer(address indexed from, address indexed to, uint256 amount)`                                      | `transfer`, `transferFrom`, `transferWithMemo`, `transferFromWithMemo`, `mint`, `mintWithMemo`, `burn`, `burnWithMemo`, `burnBlocked`, `seizeWithMemo` | En cada transferencia, acuñación (`from = address(0)`) o quema (`to = address(0)`) exitosa, incluidas las variantes con memo, de quema bloqueada y de incautación.           |
| `Approval(address indexed owner, address indexed spender, uint256 amount)`                                | `approve`, `permit`                                                                                                                                    | Se establece una asignación.                                                                                                                                                 |
| `Memo(address indexed caller, bytes32 indexed memo)`                                                      | `transferWithMemo`, `transferFromWithMemo`, `mintWithMemo`, `burnWithMemo`                                                                             | Inmediatamente después del evento `Transfer` subyacente. `caller` es el `msg.sender` de la llamada con memo.                                                                 |
| `BurnedBlocked(address indexed caller, address indexed from, uint256 amount)`                             | `burnBlocked` (obsoleto)                                                                                                                               | Además de `Transfer(from, address(0), amount)`.                                                                                                                              |
| `Seized(address indexed caller, address indexed from, address indexed to, uint256 amount)`                | `seizeWithMemo`                                                                                                                                        | Además de `Transfer(from, to, amount)` y `Memo(caller, memo)`. Registra una incautación realizada mediante transferencia.                                                    |
| `RoleGranted(bytes32 indexed role, address indexed account, address indexed sender)`                      | `grantRole`                                                                                                                                            | Se concede `role` a `account`. `sender` es el llamador original.                                                                                                             |
| `RoleRevoked(bytes32 indexed role, address indexed account, address indexed sender)`                      | `revokeRole`, `renounceRole`, `renounceLastAdmin`                                                                                                      | Se revoca `role` a `account`. `sender` es el titular del rol de administrador (`revokeRole`) o el propio `account` (`renounceRole`/`renounceLastAdmin`).                     |
| `RoleAdminChanged(bytes32 indexed role, bytes32 indexed previousAdminRole, bytes32 indexed newAdminRole)` | `setRoleAdmin`                                                                                                                                         | Cambia el rol de administrador de `role`.                                                                                                                                    |
| `LastAdminRenounced(address indexed previousAdmin)`                                                       | `renounceLastAdmin`                                                                                                                                    | Además del evento estándar `RoleRevoked(DEFAULT_ADMIN_ROLE, previousAdmin, previousAdmin)`.                                                                                  |
| `Paused(address indexed updater, PausableFeature[] features)`                                             | `pause`                                                                                                                                                | `features` es el argumento de la llamada (no el estado de pausa resultante).                                                                                                 |
| `Unpaused(address indexed updater, PausableFeature[] features)`                                           | `unpause`                                                                                                                                              | `features` es el argumento de la llamada (no el estado de pausa resultante).                                                                                                 |
| `PolicyUpdated(bytes32 indexed policyScope, uint64 oldPolicyId, uint64 newPolicyId)`                      | `updatePolicy`; también la creación del token                                                                                                          | Cambia una ranura de política del token. La asignación inicial de ranuras durante la creación también emite este evento, con `oldPolicyId == 0`.                             |
| `SupplyCapUpdated(address indexed updater, uint256 oldSupplyCap, uint256 newSupplyCap)`                   | `updateSupplyCap`                                                                                                                                      | Cambia el límite de suministro.                                                                                                                                              |
| `ContractURIUpdated()`                                                                                    | `updateContractURI`                                                                                                                                    | Sin parámetros, conforme a ERC-7572; los integradores deben volver a consultar `contractURI()`.                                                                              |
| `NameUpdated(address indexed updater, string newName)`                                                    | `updateName`                                                                                                                                           | Cambia el nombre del token. Incluye la cadena con el nuevo nombre.                                                                                                           |
| `SymbolUpdated(address indexed updater, string newSymbol)`                                                | `updateSymbol`                                                                                                                                         | Cambia el símbolo del token. Incluye la cadena con el nuevo símbolo.                                                                                                         |
| `EIP712DomainChanged()`                                                                                   | `updateName`                                                                                                                                           | Señal de cambio de dominio de ERC-5267; se emite exactamente una vez por cada llamada exitosa, inmediatamente después de `NameUpdated`. `updateSymbol` NO emite este evento. |

## [`IB20Asset`](/specifications/b20/reference/interfaces/ib20-asset) {#ib20asset}

| Evento                                                                                   | Emitido por                                      | Cuándo                                                                                                                                                                       |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `MultiplierUpdated(uint256 multiplier)`                                                  | `updateMultiplier` (setter instantáneo obsoleto) | Réplica obsoleta del topic legacy, emitida junto con `UIMultiplierUpdated` para que los indexadores que usan el topic anterior sigan funcionando.[^1]                        |
| `UIMultiplierUpdateCancelled(uint256 cancelledMultiplier, uint256 cancelledEffectiveAt)` | `cancelUIMultiplierUpdate`; `updateUIMultiplier` | Se cancela una actualización programada del multiplicador, ya sea de forma explícita o implícita, cuando `updateUIMultiplier` descarta una actualización pendiente en curso. |
| `ExtraMetadataUpdated(string key, string value)`                                         | `updateExtraMetadata`                            | Se establece, actualiza o elimina una entrada de metadatos adicionales (un `value` vacío indica eliminación).                                                                |
| `Announcement(address indexed caller, string id, string description, string uri)`        | `announce`                                       | Abre un bloque de anuncio.                                                                                                                                                   |
| `EndAnnouncement(string id)`                                                             | `announce`                                       | Cierra el bloque abierto por el `Announcement` correspondiente con el mismo `id`.                                                                                            |

[^1]: La documentación a nivel de función solo indica que `updateMultiplier` emite `MultiplierUpdated`; la función programada `updateUIMultiplier` emite únicamente `UIMultiplierUpdated`. Sin embargo, el comentario de documentación del propio evento en el código fuente también menciona `updateUIMultiplier` como emisor de `MultiplierUpdated`, lo que contradice el `@notice` de `updateUIMultiplier`. Lo señalamos aquí en lugar de optar por una de las dos versiones sin advertirlo.

## [`IB20Factory`](/specifications/b20/reference/interfaces/ib20-factory) {#ib20factory}

| Evento                                                                                                                                | Emitido por | Cuándo                                                                                                                                                                                                                                                                                              |
| ------------------------------------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `B20Created(address indexed token, B20Variant indexed variant, string name, string symbol, uint8 decimals, bytes variantEventParams)` | `createB20` | Una vez por invocación, después de que la identidad del token quede sellada y antes de que se despache cualquiera de las `initCalls`. `variantEventParams` contiene datos de identidad específicos de la variante (vacío para ASSET; `B20StablecoinEventParams` codificado en ABI para STABLECOIN). |

## [`IPolicyRegistry`](/specifications/b20/reference/interfaces/i-policy-registry) {#ipolicyregistry}

| Evento                                                                                                   | Emitido por                                                           | Cuándo                                                                                                                                                                                                                 |
| -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PolicyCreated(uint64 indexed policyId, address indexed creator, PolicyType policyType)`                 | `createPolicy`, `createPolicyWithAccounts`, `createCompositePolicy`   | Se crea una nueva política.                                                                                                                                                                                            |
| `PolicyAdminStaged(uint64 indexed policyId, address indexed currentAdmin, address indexed pendingAdmin)` | `stageUpdateAdmin`                                                    | Se prepara un nuevo administrador. `pendingAdmin == address(0)` anula una nominación previa.                                                                                                                           |
| `PolicyAdminUpdated(uint64 indexed policyId, address indexed previousAdmin, address indexed newAdmin)`   | `finalizeUpdateAdmin`, `renounceAdmin`; también al crear una política | Cambia el administrador activo. `newAdmin == address(0)` indica una renuncia; `previousAdmin == address(0)` indica la asignación inicial durante la creación.                                                          |
| `AllowlistUpdated(uint64 indexed policyId, address indexed updater, bool allowed, address[] accounts)`   | `updateAllowlist`                                                     | La pertenencia a la ALLOWLIST de una o más cuentas se establece en `allowed` en un único lote.                                                                                                                         |
| `BlocklistUpdated(uint64 indexed policyId, address indexed updater, bool blocked, address[] accounts)`   | `updateBlocklist`                                                     | La pertenencia a la BLOCKLIST de una o más cuentas se establece en `blocked` en un único lote.                                                                                                                         |
| `CompositePolicyUpdated(uint64 indexed policyId, address indexed updater, uint64[] childPolicyIds)`      | `createCompositePolicy`, `updateComposite`                            | Se establece o se reemplaza por completo el conjunto de políticas hijas de una política compuesta. Se emite al crearla y en cada actualización posterior; incluye el conjunto completo resultante de la actualización. |

## [`IActivationRegistry`](/specifications/b20/reference/interfaces/i-activation-registry) {#iactivationregistry}

| Evento                                                                | Emitido por  | Cuándo                  |
| --------------------------------------------------------------------- | ------------ | ----------------------- |
| `FeatureActivated(bytes32 indexed feature, address indexed caller)`   | `activate`   | Se activa `feature`.    |
| `FeatureDeactivated(bytes32 indexed feature, address indexed caller)` | `deactivate` | Se desactiva `feature`. |
