---
title: "Errores"
description: "Errores personalizados de B20, sus selectores y las condiciones que los provocan."
---

*Lista exhaustiva de errores personalizados, sus selectores y las condiciones que los provocan. Los selectores son el hash `keccak256` de 4 bytes de la firma del error y se calculan con `cast sig "ErrorName(types...)"`. Los parámetros de tipo enum se codifican como su `uint8` subyacente.*

*Nota: varios nombres de error se reutilizan en distintos archivos con parámetros diferentes (o sin parámetros), lo que cambia el selector. `PolicyNotFound()` ([`IPolicyRegistry`](/specifications/b20/reference/interfaces/i-policy-registry)) y `PolicyNotFound(uint64)` ([`IB20`](/specifications/b20/reference/interfaces/ib20)) son errores independientes con selectores distintos, al igual que `Unauthorized()` (`IB20` / `IPolicyRegistry`) y `Unauthorized(address)` ([`IActivationRegistry`](/specifications/b20/reference/interfaces/i-activation-registry)). En cambio, `LengthMismatch(uint256,uint256)` comparte el mismo selector en [`IB20Asset`](/specifications/b20/reference/interfaces/ib20-asset) y [`B20FactoryLib`](https://github.com/base/base-std/blob/main/src/lib/B20FactoryLib.sol): se declaran por separado, pero tienen una firma idéntica.*

## [`IB20`](/specifications/b20/reference/interfaces/ib20) {#ib20}

| Error                                                                       | Selector     | Se lanza cuando                                                                                                                                                |
| --------------------------------------------------------------------------- | ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NonPayable()`                                                              | `0x6fb1b0e9` | Se adjuntó ETH a una llamada dirigida a un selector no pagable (nonpayable) del token.                                                                         |
| `AccessControlUnauthorizedAccount(address account, bytes32 neededRole)`     | `0xe2517d3f` | `account` no tiene el rol `neededRole`.                                                                                                                        |
| `Unauthorized()`                                                            | `0x82b42900` | El llamador no superó una comprobación de autorización posicional que no puede expresarse como «falta el rol X».                                               |
| `ContractPaused(uint8 feature)`                                             | `0xfd8c4245` | La `PausableFeature` que rige la operación está en pausa.                                                                                                      |
| `InsufficientAllowance(address spender, uint256 allowance, uint256 needed)` | `0x192b9e4e` | La asignación (allowance) de `spender` es inferior a `needed` para el `transferFrom` solicitado.                                                               |
| `InsufficientBalance(address sender, uint256 balance, uint256 needed)`      | `0xdb42144d` | El saldo de `sender` es inferior a `needed` para la transferencia o quema solicitada.                                                                          |
| `InvalidSender(address sender)`                                             | `0x4c14f64c` | La dirección de origen de la transferencia no es válida (normalmente, `address(0)`).                                                                           |
| `InvalidReceiver(address receiver)`                                         | `0x9cfea583` | La dirección de destino de la transferencia no es válida (`address(0)` o cualquier dirección con prefijo B20).                                                 |
| `InvalidApprover(address approver)`                                         | `0x8bc146c4` | La dirección `owner` de la aprobación no es válida (normalmente, `address(0)`).                                                                                |
| `InvalidSpender(address spender)`                                           | `0x4e15efda` | La dirección `spender` de la aprobación no es válida (normalmente, `address(0)`).                                                                              |
| `InvalidAmount()`                                                           | `0x2c5211c6` | Un argumento de cantidad era cero cuando se requiere un valor distinto de cero. No se usa para los argumentos de cantidad de ERC-20.                           |
| `EmptyFeatureSet()`                                                         | `0x4861ff45` | Se pasó un array vacío a una función que requiere al menos un elemento.                                                                                        |
| `InvalidSupplyCap(uint256 currentSupply, uint256 proposedCap)`              | `0x0a3780ce` | El límite de suministro propuesto es inferior al `totalSupply` actual o superior a `type(uint128).max`.                                                        |
| `SupplyCapExceeded(uint256 cap, uint256 attempted)`                         | `0x4b344b11` | La acuñación haría que `totalSupply` superara el límite configurado.                                                                                           |
| `PolicyForbids(bytes32 policyScope, uint64 policyId)`                       | `0xa43fec12` | Un slot de política denegó la operación.                                                                                                                       |
| `PolicyNotFound(uint64 policyId)`                                           | `0xcccad523` | El ID de política proporcionado no existe en el registro de políticas.                                                                                         |
| `UnsupportedPolicyType(bytes32 policyScope)`                                | `0xcdd98a4a` | `policyScope` no es un slot compatible con este token (o con su variante).                                                                                     |
| `AccountNotSeizable(address account)`                                       | `0x91dbbc8d` | Se llamó a `seizeWithMemo` sobre un `from` que está exento de incautación (sigue autorizado) según `SEIZE_EXEMPT_POLICY`.                                      |
| `AccountNotBlocked(address account)`                                        | `0x64a5cb46` | Se llamó a la función obsoleta `burnBlocked` sobre un `from` que está autorizado actualmente según `TRANSFER_SENDER_POLICY` (es decir, que no está bloqueado). |
| `ExpiredSignature(uint256 deadline)`                                        | `0xbd2a913c` | Se envió un `permit` de EIP-2612 con un `deadline` estrictamente menor que `block.timestamp`.                                                                  |
| `InvalidSigner(address signer, address owner)`                              | `0x7ba5ffb5` | La recuperación ECDSA de un `permit` de EIP-2612 devolvió `signer`, que no coincide con el `owner` declarado.                                                  |
| `LastAdminCannotRenounce()`                                                 | `0x361513e7` | El único administrador restante llamó a `renounceRole(DEFAULT_ADMIN_ROLE, ...)`.                                                                               |
| `NotSoleAdmin()`                                                            | `0x2a98e73b` | Se llamó a `renounceLastAdmin()` cuando otras cuentas también tienen `DEFAULT_ADMIN_ROLE`.                                                                     |
| `AccessControlBadConfirmation()`                                            | `0x6697b232` | El argumento `callerConfirmation` de `renounceRole` no era `msg.sender`.                                                                                       |
