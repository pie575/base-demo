Las interfaces de B20 describen las superficies de los precompilados de token, fábrica y registro. Consulta la referencia enlazada para ver el comportamiento de cada función. El archivo canónico de Solidity está en [`base-std`](https://github.com/base/base-std/tree/main/src/interfaces).

## Importaciones para copiar y pegar {#copy-and-paste-imports}

Usa estas importaciones con el remapping de Foundry `base-std/=src/`.

### IB20 {#ib20}

```solidity filename="IB20.sol"
import {IB20} from "base-std/interfaces/IB20.sol";
```

### IB20Asset {#ib20asset}

```solidity filename="IB20Asset.sol"
import {IB20Asset} from "base-std/interfaces/IB20Asset.sol";
```

### IB20Stablecoin {#ib20stablecoin}

```solidity filename="IB20Stablecoin.sol"
import {IB20Stablecoin} from "base-std/interfaces/IB20Stablecoin.sol";
```

### IB20Factory {#ib20factory}

```solidity filename="IB20Factory.sol"
import {IB20Factory} from "base-std/interfaces/IB20Factory.sol";
```

### IPolicyRegistry {#ipolicyregistry}

### IActivationRegistry {#iactivationregistry}

### IERC8056 {#ierc8056}

