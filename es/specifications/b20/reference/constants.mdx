## Direcciones de precompilados {#precompile-addresses}

*Direcciones fijas de los precompilados singleton de Base. Consulta [`StdPrecompiles`](https://github.com/base/base-std/blob/main/src/StdPrecompiles.sol).*

| Nombre                        | Valor                                        | Propósito                                                                                                                                                                                                                                 |
| ----------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `B20_FACTORY_ADDRESS`         | `0xB20f000000000000000000000000000000000000` | Despliega y localiza tokens B-20; todas las instancias de activo y de stablecoin se crean a través de [`IB20Factory`](/es/specifications/b20/reference/interfaces#ib20factory) en esta dirección.                                            |
| `POLICY_REGISTRY_ADDRESS`     | `0x8453000000000000000000000000000000000002` | Almacena políticas de lista de permitidos, de lista de bloqueados y compuestas, y responde a las comprobaciones `isAuthorized` que consultan todos los ámbitos de política (consulta [Políticas](/es/specifications/b20/concepts/policies)). |
| `ACTIVATION_REGISTRY_ADDRESS` | `0x8453000000000000000000000000000000000001` | Controla si una variante o funcionalidad de B-20 está activa en una cadena concreta; la factory lo comprueba antes de crear dicha variante.                                                                                               |

## Límites de funcionalidades y validación {#feature-and-validation-bounds}

*Máscaras de bits y límites inclusivos que se usan para las funcionalidades pausables y para validar la creación de B20Asset. Consulta [`B20Constants`](https://github.com/base/base-std/blob/main/src/lib/B20Constants.sol).*

| Nombre                | Valor               | Propósito                                                                                                                                                                             |
| --------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ALL_FEATURES_PAUSED` | `15` (`0b1111`)     | Máscara de bits con todos los bits de `PausableFeature` activados (`TRANSFER \| MINT \| BURN \| SEIZE`).                                                                              |
| `MIN_ASSET_DECIMALS`  | `6`                 | Límite inferior inclusivo para `B20AssetCreateParams.decimals`; el mínimo que espera la mayoría de las integraciones de nivel stablecoin.                                             |
| `MAX_ASSET_DECIMALS`  | `18`                | Límite superior inclusivo para `B20AssetCreateParams.decimals`; el máximo aceptado por la comunidad ERC-20, que todas las billeteras e indexadores habituales muestran correctamente. |
| `MAX_SUPPLY_CAP`      | `type(uint128).max` | Límite superior inclusivo para el tope de suministro (y, por tanto, para `totalSupply`); también sirve como valor centinela de suministro ilimitado («sin tope»).                     |

## Constantes de precisión de la variante de activo {#asset-variant-precision-constants}

*Constantes de punto fijo que utiliza la superficie de multiplicador/rebasing. Consulta [`IB20Asset`](/es/specifications/b20/reference/interfaces#ib20asset).*

| Nombre              | Valor               | Propósito                                                                                                                                                                                                                                  |
| ------------------- | ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `WAD_PRECISION`     | `1e18`              | Precisión de punto fijo con la que se escala `multiplier`; `multiplier`, `toUIAmount` y `fromUIAmount` dividen o multiplican por este valor.                                                                                               |
| `MAX_UI_MULTIPLIER` | `type(uint128).max` | Multiplicador máximo que aceptan los setters; es la protección contra desbordamiento que aplican `updateMultiplier` y `updateUIMultiplier`. Se expone para que los llamadores puedan consultar el límite sin provocar `InvalidMultiplier`. |
