## Método RPC de salida de L2 {#l2-output-rpc-method}

El nodo de rollup tiene su propio método RPC, `optimism_outputAtBlock`, que devuelve un hash de 32
bytes correspondiente al [output root de L2](/es/specifications/reference/glossary#l2-output-root).

### Estructuras {#structures}

Aquí se definen los tipos que utilizan los métodos de la API del nodo de rollup.
Estos tipos extienden los definidos en las [especificaciones de la Engine API][engine-structures].

#### BlockID {#blockid}

* `hash`: `DATA`, 32 bytes
* `number`: `QUANTITY`, 64 bits

#### L1BlockRef {#l1blockref}

* `hash`: `DATA`, 32 bytes
* `number`: `QUANTITY`, 64 bits
* `parentHash`: `DATA`, 32 bytes
* `timestamp`: `QUANTITY`, 64 bits

#### L2BlockRef {#l2blockref}

* `hash`: `DATA`, 32 bytes
* `number`: `QUANTITY`, 64 bits
* `parentHash`: `DATA`, 32 bytes
* `timestamp`: `QUANTITY`, 64 bits
* `l1origin`: `BlockID`
* `sequenceNumber`: `QUANTITY`, 64 bits: distancia con respecto al primer bloque de la época

#### SyncStatus {#syncstatus}

Representa una instantánea del estado del controlador del rollup.

* `current_l1`: `Object` - instancia de [`L1BlockRef`](#l1blockref).
* `current_l1_finalized`: `Object` - instancia de [`L1BlockRef`](#l1blockref).
* `head_l1`: `Object` - instancia de [`L1BlockRef`](#l1blockref).
* `safe_l1`: `Object` - instancia de [`L1BlockRef`](#l1blockref).
* `finalized_l1`: `Object` - instancia de [`L1BlockRef`](#l1blockref).
* `unsafe_l2`: `Object` - instancia de [`L2BlockRef`](#l2blockref).
* `safe_l2`: `Object` - instancia de [`L2BlockRef`](#l2blockref).
* `finalized_l2`: `Object` - instancia de [`L2BlockRef`](#l2blockref).
* `pending_safe_l2`: `Object` - instancia de [`L2BlockRef`](#l2blockref).
* `queued_unsafe_l2`: `Object` - instancia de [`L2BlockRef`](#l2blockref).

### API del método de salida {#output-method-api}

Los tipos de entrada y de retorno que se usan aquí son los definidos en las [especificaciones de la Engine API][engine-structures].

[engine-structures]: https://github.com/ethereum/execution-apis/blob/main/src/engine/paris.md#structures

#### `optimism_outputAtBlock` {#optimism_outputatblock}

Devuelve un output root y sus metadatos asociados para un bloque de L2 dado.

**Parámetros**

| Nombre        | Tipo                | Descripción                     |
| :------------ | :------------------ | :------------------------------ |
| `blockNumber` | `QUANTITY`, 64 bits | Número de bloque de L2 (entero) |

**Valores devueltos**

| Nombre                  | Tipo             | Descripción                                               |
| :---------------------- | :--------------- | :-------------------------------------------------------- |
| `version`               | `DATA`, 32 bytes | Número de versión del output root, empezando por `0`      |
| `outputRoot`            | `DATA`, 32 bytes | El output root                                            |
| `blockRef`              | `Object`         | Instancia de [`L2BlockRef`](#l2blockref)                  |
| `withdrawalStorageRoot` | `DATA`, 32 bytes | Raíz de almacenamiento del contrato `L2ToL1MessagePasser` |
| `stateRoot`             | `DATA`, 32 bytes | La raíz de estado                                         |
| `syncStatus`            | `Object`         | Instancia de [`SyncStatus`](#syncstatus)                  |
