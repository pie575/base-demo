---
title: 'eth_getBlockTransactionCountByHash'
sidebarTitle: 'eth_getBlockTransactionCountByHash'
description: 'Devuelve el número de transacciones de un bloque a partir de su hash.'
---

Devuelve el número de transacciones del bloque que corresponde al hash de bloque indicado.

## Parámetros {#parameters}

<ParamField body="blockHash" type="string" required>
  El hash del bloque, de 32 bytes.
</ParamField>

## Valor devuelto {#returns}

<ResponseField name="result" type="string">
  El número de transacciones del bloque, expresado como un entero hexadecimal. `null` si no se encuentra ningún bloque.
</ResponseField>

## Ejemplo {#example}

<CodeGroup>
  ```json Request
  {
    "jsonrpc": "2.0",
    "method": "eth_getBlockTransactionCountByHash",
    "params": ["0x5c330e55a190f82ea486b61e5b12e27dfb4fb3cecfc5746886ef38ca1281bce8"],
    "id": 1
  }
  ```

  ```json Response
  {
    "jsonrpc": "2.0",
    "id": 1,
    "result": "0x1f"
  }
  ```
</CodeGroup>
