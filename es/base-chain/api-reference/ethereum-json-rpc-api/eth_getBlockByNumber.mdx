Devuelve información sobre un bloque a partir de su número.

<Tip>
  **Flashblocks:** Consulta `https://mainnet.base.org` con `"pending"` para obtener en tiempo real el Flashblock en curso: un objeto de bloque real que se actualiza cada ~200 ms con nuevas transacciones preconfirmadas. La estructura de la respuesta es idéntica; la única diferencia es que el bloque aún no está sellado.
</Tip>

## Parámetros {#parameters}

<ParamField body="block" type="string" required>
  Número de bloque en hexadecimal, o `"latest"`, `"pending"`, `"safe"`, `"finalized"` o `"earliest"`. Usa `"pending"` para obtener el bloque en curso.
</ParamField>

<ParamField body="fullTransactions" type="boolean" required>
  Si es `true`, devuelve los objetos de transacción completos. Si es `false`, devuelve solo los hashes de las transacciones.
</ParamField>

## Valor de retorno {#returns}

<ResponseField name="result" type="object">
  Un objeto de bloque, o `null` si no se encontró ningún bloque.

  <Expandable title="Campos del bloque">
    <ResponseField name="number" type="string">Número de bloque en hexadecimal. `null` si está pendiente.</ResponseField>
    <ResponseField name="hash" type="string">Hash del bloque. `null` si está pendiente.</ResponseField>
    <ResponseField name="parentHash" type="string">Hash del bloque padre.</ResponseField>
    <ResponseField name="nonce" type="string">Nonce de PoW. Siempre `"0x0000000000000000"` en Base (PoS).</ResponseField>
    <ResponseField name="sha3Uncles" type="string">Hash de la lista de uncles. Siempre vacía en Base.</ResponseField>
    <ResponseField name="logsBloom" type="string">Filtro de Bloom de los logs del bloque.</ResponseField>
    <ResponseField name="transactionsRoot" type="string">Raíz del trie de transacciones.</ResponseField>
    <ResponseField name="stateRoot" type="string">Raíz del trie de estado final.</ResponseField>
    <ResponseField name="receiptsRoot" type="string">Raíz del trie de recibos.</ResponseField>
    <ResponseField name="miner" type="string">Dirección del destinatario de las comisiones (coinbase).</ResponseField>
    <ResponseField name="difficulty" type="string">Siempre `"0x0"` en Base (PoS).</ResponseField>
    <ResponseField name="mixHash" type="string">Presente en todos los bloques; se reutiliza para el consenso PoS (bytes32 en hexadecimal).</ResponseField>
    <ResponseField name="extraData" type="string">Campo de datos arbitrarios definido por el sequencer.</ResponseField>
    <ResponseField name="size" type="string">Tamaño del bloque en bytes (hexadecimal).</ResponseField>
    <ResponseField name="gasLimit" type="string">Gas máximo permitido en este bloque (hexadecimal).</ResponseField>
    <ResponseField name="gasUsed" type="string">Gas total utilizado en este bloque (hexadecimal).</ResponseField>
    <ResponseField name="timestamp" type="string">Marca de tiempo Unix (hexadecimal).</ResponseField>
    <ResponseField name="transactions" type="array">Array de hashes de transacciones u objetos de transacción completos.</ResponseField>
    <ResponseField name="uncles" type="array">Siempre `[]` en Base.</ResponseField>
    <ResponseField name="withdrawals" type="array">Siempre `[]` en Base.</ResponseField>
    <ResponseField name="withdrawalsRoot" type="string">Raíz de Merkle de la lista de retiros (EIP-4895, bytes32 en hexadecimal).</ResponseField>
    <ResponseField name="baseFeePerGas" type="string">Comisión base por gas de EIP-1559 (hexadecimal).</ResponseField>
    <ResponseField name="blobGasUsed" type="string">Gas de blob total utilizado (EIP-4844, hexadecimal).</ResponseField>
    <ResponseField name="excessBlobGas" type="string">Exceso de gas de blob para calcular la comisión de blob (EIP-4844, hexadecimal).</ResponseField>
    <ResponseField name="parentBeaconBlockRoot" type="string">Raíz del bloque beacon padre (EIP-4788).</ResponseField>
    <ResponseField name="requestsHash" type="string">Hash de las solicitudes (EIP-7685).</ResponseField>
  </Expandable>
</ResponseField>

## Campos de respuesta específicos de Flashblocks {#flashblock-specific-response-fields}

Al consultar `"pending"`, la respuesta es una instantánea en tiempo real del bloque que se está construyendo. Algunos campos se comportan de forma distinta:

| Campo          | `latest` estándar                | `pending` de Flashblocks                             |
| -------------- | -------------------------------- | ---------------------------------------------------- |
| `number`       | Número del bloque sellado        | Número del bloque actual (en construcción)           |
| `hash`         | Hash final del bloque            | Hash del bloque parcial en este índice de Flashblock |
| `gasUsed`      | Gas utilizado final              | Gas acumulado utilizado hasta este Flashblock        |
| `transactions` | Todas las transacciones selladas | Transacciones preconfirmadas hasta el momento        |
| `blobGasUsed`  | Gas de blob utilizado final      | Se propaga desde el estado acumulado de Flashblocks  |

    -X POST \

      "jsonrpc": "2.0",
      "method": "eth_getBlockByNumber",
      "params": ["latest", false],
      "id": 1
    }'
