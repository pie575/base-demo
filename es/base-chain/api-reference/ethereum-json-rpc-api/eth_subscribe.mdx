sidebarTitle: 'eth_subscribe'
description: 'Crea una suscripción WebSocket en tiempo real a nuevos bloques, logs y transacciones pendientes.'
---

Crea una suscripción a eventos en tiempo real mediante una conexión WebSocket. Devuelve un ID de suscripción; los eventos se envían como notificaciones `eth_subscription` sin que el cliente tenga que hacer sondeos periódicos.

<Note>
  Los endpoints públicos de Base (`mainnet.base.org`, `sepolia.base.org`) son **solo HTTP**. Las conexiones WebSocket no están disponibles en los endpoints públicos de Base: elige un proveedor compatible con WebSocket en [Builder Stack](/es/get-started/builder-stack).
</Note>

## Parámetros {#parameters}

<ParamField body="subscriptionType" type="string" required>
  El tipo de evento al que se desea suscribir.
</ParamField>

<ParamField body="filterOptions" type="object">
  Opciones de filtrado opcionales. Solo se aplican al tipo de suscripción `"logs"`.

  <Expandable title="Opciones de filtrado (solo logs)">
    <ParamField body="address" type="string | array">
      Una dirección de contrato o un arreglo de direcciones por las que filtrar. Opcional.
    </ParamField>

    <ParamField body="topics" type="array">
      Arreglo de filtros de topics con el mismo formato que en `eth_getLogs`. Opcional.
    </ParamField>
  </Expandable>
</ParamField>

## Tipos de suscripción {#subscription-types}

| Tipo                     | Descripción                                                            | Carga útil de la notificación                                                                                                                                                                        |
| ------------------------ | ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `newHeads`               | Se activa con cada nuevo bloque que se añade a la cadena               | Objeto completo del encabezado del bloque, con la misma estructura que devuelve [`eth_getBlockByNumber`](/es/base-chain/api-reference/ethereum-json-rpc-api/eth_getBlockByNumber) con `hydrated: false` |
| `logs`                   | Se activa con cada nuevo log que cumpla los criterios del filtro       | Objeto de log (consulta más abajo)                                                                                                                                                                   |
| `newPendingTransactions` | Se activa con cada nuevo hash de transacción que se añade a la mempool | Cadena con el hash de la transacción                                                                                                                                                                 |

## Valor devuelto {#returns}

<ResponseField name="result" type="string">
  Un ID de suscripción codificado en hexadecimal. Todas las notificaciones de eventos de esta suscripción incluyen este ID en `params.subscription`.
</ResponseField>

Las notificaciones de eventos llegan como mensajes JSON-RPC no solicitados:

```json Event Notification lines wrap expandable
{
  "jsonrpc": "2.0",
  "method": "eth_subscription",
  "params": {
    "subscription": "0x1887ec8b9589ccad00000000000532da",
    "result": { ... }
  }
}
```
