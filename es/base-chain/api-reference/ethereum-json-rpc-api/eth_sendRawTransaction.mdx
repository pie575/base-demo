Envía a la red una transacción prefirmada y codificada en RLP, y devuelve su hash.

<Tip>
  **Flashblocks:** envía la transacción a `https://mainnet.base.org` para que se tenga en cuenta en el siguiente Flashblock (~200 ms). Usa [`base_transactionStatus`](/es/base-chain/api-reference/flashblocks-api/base_transactionStatus) para confirmar que ha llegado a la mempool y suscríbete a [`newFlashblockTransactions`](/es/base-chain/api-reference/flashblocks-api/newFlashblockTransactions) para detectar la preconfirmación.
</Tip>

## Parámetros {#parameters}

<ParamField body="data" type="string" required>
  La transacción firmada, expresada como una cadena hexadecimal codificada en RLP. Suele generarse con una biblioteca de billetera como viem, ethers.js o web3.js.
</ParamField>

## Valores devueltos {#returns}

<ResponseField name="result" type="string">
  El hash de 32 bytes de la transacción, si esta se aceptó en la mempool.
</ResponseField>

## Códigos de error {#error-codes}

| Código   | Mensaje                                    | Descripción                                                                    |
| -------- | ------------------------------------------ | ------------------------------------------------------------------------------ |
| `-32000` | nonce too low                              | El nonce de la transacción es inferior al nonce actual de la cuenta.           |
| `-32000` | insufficient funds for gas * price + value | El saldo del remitente no alcanza para cubrir el costo del gas y el valor.     |
| `-32000` | already known                              | Ya hay una transacción idéntica en la mempool.                                 |
| `-32000` | replacement transaction underpriced        | Una transacción de reemplazo debe aumentar el precio del gas al menos un 10 %. |
