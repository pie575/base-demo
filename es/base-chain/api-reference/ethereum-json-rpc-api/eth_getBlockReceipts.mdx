Devuelve todos los recibos de transacciones de un bloque determinado.

<Warning>
  Este método devuelve HTTP 403 en los endpoints RPC públicos de Base (`mainnet.base.org`, `sepolia.base.org`). Requiere un proveedor RPC dedicado o de terceros. Consulta el [Builder Stack](/es/get-started/builder-stack) para ver las opciones disponibles.
</Warning>

<Tip>
  **Flashblocks:** Envía una consulta a `https://mainnet.base.org` con `"pending"` para obtener los recibos de todas las transacciones preconfirmadas del Flashblock actual.
</Tip>

## Parámetros {#parameters}

<ParamField body="block" type="string" required>
  Número de bloque en hexadecimal, o bien `"latest"`, `"pending"`, `"safe"`, `"finalized"` o `"earliest"`.
</ParamField>

## Valor devuelto {#returns}

<ResponseField name="result" type="array">
  Array de objetos de recibo, uno por cada transacción del bloque. Consulta [`eth_getTransactionReceipt`](/es/base-chain/api-reference/ethereum-json-rpc-api/eth_getTransactionReceipt) para ver la estructura del objeto de recibo.
</ResponseField>

## Ejemplo {#example}

<CodeGroup>
  ```bash Estándar (latest)
  curl https://mainnet.base.org \
    -X POST -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getBlockReceipts","params":["latest"],"id":1}'
  ```

  ```bash Flashblocks (pending)
  curl https://mainnet.base.org \
    -X POST -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getBlockReceipts","params":["pending"],"id":1}'
  ```
