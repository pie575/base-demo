Devuelve información sobre una transacción a partir de un número de bloque y de la posición de índice de la transacción dentro de ese bloque.

## Parámetros {#parameters}

<ParamField body="block" type="string" required>
  Número de bloque en hexadecimal, o bien `"latest"`, `"pending"`, `"safe"`, `"finalized"` o `"earliest"`.
</ParamField>

<ParamField body="index" type="string" required>
  Posición de índice de la transacción en el bloque, expresada como un entero hexadecimal.
</ParamField>

## Valor devuelto {#returns}

<ResponseField name="result" type="object | null">
  Un objeto de transacción, o `null` si no se encuentra. Consulta [`eth_getTransactionByHash`](/es/base-chain/api-reference/ethereum-json-rpc-api/eth_getTransactionByHash) para ver la lista completa de campos.
</ResponseField>
