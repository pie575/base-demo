Simula uno o varios paquetes de transacciones sobre el estado preconfirmado actual del Flashblock. Admite sobrescritura de estado, simulación de varios bloques y rastreo opcional de transferencias.

<Info>
  Solo está disponible en los endpoints de Flashblocks: `https://mainnet.base.org` / `https://sepolia.base.org`.
</Info>

## Parámetros {#parameters}

<ParamField body="simulationPayload" type="object" required>
  La configuración de la simulación.

  <Expandable title="Campos de Simulation Payload">
    <ParamField body="blockStateCalls" type="array" required>
      Array de objetos de llamada de estado de bloque. Cada objeto representa un bloque simulado.

      <Expandable title="Campos de Block State Call">
        <ParamField body="calls" type="array">
          Array de objetos de llamada de transacción que se simularán en este bloque.
        </ParamField>

        <ParamField body="stateOverrides" type="object">
          Sobrescrituras de estado por dirección que se aplican antes de la simulación (p. ej., saldo, nonce, código, almacenamiento). Opcional.
        </ParamField>

        <ParamField body="blockOverrides" type="object">
          Sobrescrituras a nivel de bloque (p. ej., `number`, `timestamp`). Opcional.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="traceTransfers" type="boolean">
      Si es `true`, los eventos de transferencia de ETH se incluyen como logs en el resultado. El valor predeterminado es `false`.
    </ParamField>

    <ParamField body="validation" type="boolean">
      Si es `true`, se exige la validación de las transacciones (nonce, saldo). El valor predeterminado es `false`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="blockParameter" type="string" required>
  Usa `"pending"` para simular sobre el estado actual del Flashblock.
</ParamField>

## Valores devueltos {#returns}

<ResponseField name="result" type="array">
  Array de resultados de bloques simulados, uno por cada entrada de `blockStateCalls`. Cada entrada es un objeto de bloque completo que incluye un campo `calls` junto a los campos de bloque estándar.

  <Expandable title="Campos del resultado del bloque">
    <ResponseField name="number" type="string">Número del bloque simulado (hex).</ResponseField>
    <ResponseField name="hash" type="string">Hash del bloque simulado.</ResponseField>
    <ResponseField name="parentHash" type="string">Hash del bloque padre.</ResponseField>
    <ResponseField name="timestamp" type="string">Marca de tiempo del bloque (hex).</ResponseField>
    <ResponseField name="gasLimit" type="string">Límite de gas (hex).</ResponseField>
    <ResponseField name="gasUsed" type="string">Gas total consumido por las llamadas simuladas (hex).</ResponseField>
    <ResponseField name="baseFeePerGas" type="string">Tarifa base por unidad de gas (hex).</ResponseField>
    <ResponseField name="stateRoot" type="string">Siempre `"0x000...000"`: la simulación no confirma el estado en el trie.</ResponseField>

    <ResponseField name="calls" type="array">
      Array de resultados de cada llamada.

      <Expandable title="Campos del resultado de la llamada">
        <ResponseField name="status" type="string">`"0x1"` si tiene éxito, `"0x0"` si falla.</ResponseField>
        <ResponseField name="gasUsed" type="string">Gas consumido, como entero hexadecimal.</ResponseField>
        <ResponseField name="returnData" type="string">Datos de retorno codificados en hexadecimal.</ResponseField>
        <ResponseField name="logs" type="array">Logs emitidos (incluidos los logs de transferencias de ETH si `traceTransfers` es `true`).</ResponseField>
        <ResponseField name="error" type="string">Motivo de la reversión si la llamada falló. Opcional.</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
