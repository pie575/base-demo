Base ofrece una única API JSON-RPC, totalmente compatible con la EVM, en dos niveles de rendimiento. Para pasar de confirmaciones de bloque de 2 segundos a preconfirmaciones de 200 ms, basta con cambiar una URL y una etiqueta de bloque.

## Redes {#networks}

Para consultar los detalles de la red, los endpoints RPC y la configuración de la billetera, consulta [Conectarse a Base](/base-chain/quickstart/connecting-to-base).

<Note>
  Los endpoints públicos de Base son **solo HTTP**. Las conexiones RPC por WebSocket (`eth_subscribe`, `newHeads`, `logs`) no están disponibles en los endpoints públicos de Base; elige un proveedor compatible con WebSocket en el [Builder Stack](/es/get-started/builder-stack).
</Note>

## Flashblocks {#flashblocks}

Todos los endpoints públicos de Base son compatibles con Flashblocks. Todos los métodos `eth_` estándar funcionan exactamente igual, y la etiqueta de bloque `pending` refleja el **bloque preconfirmado en curso**, que se actualiza cada ~200 ms con nuevos lotes de transacciones ordenadas por el secuenciador.

Llamadas como `eth_getBalance`, `eth_getStorageAt` y `eth_call` se ejecutan sobre el estado real del secuenciador hasta 1,8 segundos antes de que se selle el bloque, con una latencia inferior a un segundo.

### API de Flashblocks {#flashblocks-api}

Métodos de preconfirmación para obtener señales de transacciones en menos de un segundo en Base. Estos métodos permiten leer el estado, simular paquetes y transmitir eventos en streaming hasta ~1,8 segundos antes de que se selle un bloque.

| Método                                                                                           | Descripción                                                    |
| ------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| [eth&#95;simulateV1](/es/base-chain/api-reference/flashblocks-api/eth_simulateV1)                   | Simula paquetes de transacciones sobre el estado preconfirmado |
| [base&#95;transactionStatus](/es/base-chain/api-reference/flashblocks-api/base_transactionStatus)   | Comprueba si el mempool ha recibido una transacción            |
| [newFlashblockTransactions](/es/base-chain/api-reference/flashblocks-api/newFlashblockTransactions) | Se suscribe a transacciones preconfirmadas individuales        |
| [pendingLogs](/es/base-chain/api-reference/flashblocks-api/pendingLogs)                             | Se suscribe a registros filtrados de transacciones preconfirmadas   |
| [newFlashblocks](/es/base-chain/api-reference/flashblocks-api/newFlashblocks)                       | Se suscribe al flujo completo de payloads de Flashblocks       |

### Debug API {#debug-api}

Utilidades de desarrollo y depuración para inspeccionar transacciones en profundidad y reproducir bloques. Los métodos de depuración vuelven a ejecutar las transacciones y tienen un alto coste computacional; la disponibilidad y los límites de tasa varían según el proveedor del [Builder Stack](/es/get-started/builder-stack).

| Método                                                                                       | Descripción                                                          |
| -------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| [debug&#95;traceTransaction](/es/base-chain/api-reference/debug-api/debug_traceTransaction)     | Traza completa de ejecución de la EVM para una transacción           |
| [debug&#95;traceBlockByHash](/es/base-chain/api-reference/debug-api/debug_traceBlockByHash)     | Trazas de la EVM de todas las transacciones de un bloque, por hash   |
| [debug&#95;traceBlockByNumber](/es/base-chain/api-reference/debug-api/debug_traceBlockByNumber) | Trazas de la EVM de todas las transacciones de un bloque, por número |

## Formato de solicitud y respuesta {#request-response-format}

Todas las solicitudes son HTTP POST con `Content-Type: application/json`.

| Campo     | Tipo   | Descripción                     |                                                        |
| :-------- | :----- | :------------------------------ | ------------------------------------------------------ |
| `jsonrpc` | string | Siempre `"2.0"`                 |                                                        |
| `method`  | string | Nombre del método RPC           |                                                        |
| `params`  | array  | Parámetros del método, en orden |                                                        |
| `id`      | number | string                          | Identificador que se devuelve tal cual en la respuesta |

**Solicitud:**

```json Request
{
  "jsonrpc": "2.0",
  "method": "eth_getBalance",
  "params": ["0x742d35Cc6634C0532925a3b8D4C9dD0b4f3BaEa", "pending"],
  "id": 1
}
```

**Respuesta exitosa:**

```json Success Response
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": "0x1a055690d9db80000"
}
```

**Respuesta de error:**

```json Error Response lines wrap expandable
{
  "jsonrpc": "2.0",
  "id": 1,
  "error": {
    "code": -32602,
    "message": "Invalid params"
  }
}
```

## Códigos de error {#error-codes}

| Código   | Nombre           | Descripción                                     |
| -------- | ---------------- | ----------------------------------------------- |
| `-32700` | Parse error      | JSON no válido                                  |
| `-32600` | Invalid request  | No es un objeto JSON-RPC 2.0 válido             |
| `-32601` | Method not found | El método no existe o no está disponible        |
| `-32602` | Invalid params   | Parámetros del método no válidos                |
| `-32603` | Internal error   | Error interno de JSON-RPC                       |
| `-32000` | Server error     | Error específico del nodo (consulta el mensaje) |

## Parámetros de bloque {#block-parameters}

| Valor         | Estándar                                    | Flashblocks                                                   |
| ------------- | ------------------------------------------- | ------------------------------------------------------------- |
| `"latest"`    | Bloque sellado más reciente                 | Bloque sellado más reciente                                   |
| `"pending"`   | Estado del pool de transacciones no minadas | **Flashblock actual en construcción (resolución de ~200 ms)** |
| `"safe"`      | Último bloque seguro                        | Último bloque seguro                                          |
| `"finalized"` | Último bloque finalizado                    | Último bloque finalizado                                      |
| `"earliest"`  | Bloque génesis                              | Bloque génesis                                                |
| `"0x<n>"`     | Bloque específico por número                | Bloque específico por número                                  |
