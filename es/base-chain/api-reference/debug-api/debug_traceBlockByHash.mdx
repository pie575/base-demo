---
title: 'debug_traceBlockByHash'
sidebarTitle: 'debug_traceBlockByHash'
description: 'Devuelve las trazas de ejecución de la EVM de todas las transacciones de un bloque a partir de su hash.'
---

Vuelve a ejecutar todas las transacciones de un bloque identificado por su hash y devuelve una traza de ejecución para cada una de ellas.

<Warning>
  Los métodos de depuración vuelven a ejecutar todas las transacciones del bloque y tienen un alto coste computacional. Su disponibilidad varía según el proveedor del [Builder Stack](/es/get-started/builder-stack).
</Warning>

## Parámetros {#parameters}

<ParamField body="blockHash" type="string" required>
  El hash del bloque, de 32 bytes.
</ParamField>

<ParamField body="traceOptions" type="object">
  Configuración opcional del rastreo. Acepta los mismos campos que [`debug_traceTransaction`](/es/base-chain/api-reference/debug-api/debug_traceTransaction).
</ParamField>

## Valores devueltos {#returns}

<ResponseField name="result" type="array">
  Un array de objetos de resultado de traza, uno por cada transacción del bloque.

  <Expandable title="Campos del resultado de traza">
    <ResponseField name="txHash" type="string">El hash de la transacción.</ResponseField>
    <ResponseField name="result" type="object">La traza de ejecución de esta transacción. Tiene el mismo formato que [`debug_traceTransaction`](/es/base-chain/api-reference/debug-api/debug_traceTransaction).</ResponseField>
  </Expandable>
</ResponseField>
