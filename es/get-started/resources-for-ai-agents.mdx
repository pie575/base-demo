Usa esta página como punto de partida cuando quieras que un asistente de IA desarrolle sobre Base. Aquí encontrarás tres formas de darle a un asistente contexto sobre Base: archivos estáticos de documentación, una conexión MCP en tiempo real y skills instalables. También encontrarás puntos de entrada recomendados para los flujos de trabajo más habituales.

## Configuración rápida {#quick-setup}

Conecta tu agente a la documentación de Base con un solo comando. Elige el método que mejor se adapte a tu herramienta.

### Servidor MCP {#mcp-server}

Una conexión en tiempo real permite que tu asistente busque y consulte la documentación de Base cuando lo necesite, para que siempre tenga información actualizada.

<CodeGroup>
  ```sh Claude Code
  claude mcp add --transport http base-docs https://docs.base.org/mcp
  ```

  ```sh Codex CLI
  codex mcp add base-docs --url https://docs.base.org/mcp
  ```

  ```json Cursor / manual config
  {
    "mcpServers": {
      "base-docs": {
        "url": "https://docs.base.org/mcp"
      }
    }
  }
  ```
</CodeGroup>

Consulta la [guía completa de configuración de MCP](/es/get-started/docs-mcp) para Cursor, Windsurf y otros editores.

### Archivos estáticos de documentación {#static-docs-files}

Úsalos cuando quieras cargar el contexto con una sola solicitud en lugar de mantener una conexión en tiempo real.

| Archivo                                                | Qué contiene                                  | Cuándo usarlo                                           |
| ------------------------------------------------------ | --------------------------------------------- | ------------------------------------------------------- |
| [`llms.txt`](https://docs.base.org/llms.txt)           | Índice de páginas con títulos y descripciones | Averiguar qué documentación existe antes de profundizar |
| [`llms-full.txt`](https://docs.base.org/llms-full.txt) | Documentación completa en un solo archivo     | Dar a un asistente un contexto amplio de una sola vez   |

Todas las páginas de la documentación también están disponibles en Markdown sin formato. Añade `.md` a cualquier URL:

```txt Markdown URL
https://docs.base.org/get-started/resources-for-ai-agents.md
```

### Skills {#skills}

Las Skills son flujos de trabajo instalables para agentes que cubren tareas habituales en Base, como conectarse a Base, desplegar contratos, ejecutar un nodo, entre otras. Ofrecen a tu asistente una guía paso a paso para que no tenga que recopilar por su cuenta la información dispersa en la documentación.

```sh Terminal
npx skills install base/skills -g
```

Explora las skills disponibles en el [repositorio de skills de Base](https://github.com/base/skills).
