Base es una cadena EVM estándar, así que cualquier herramienta, billetera o biblioteca de Ethereum funciona sin cambios. Solo tienes que apuntarla a los datos de red que aparecen a continuación.

## Detalles de la red {#network-details}

|                       | Base Mainnet                         | Base Sepolia (red de pruebas)                        |
| --------------------- | ------------------------------------ | ---------------------------------------------------- |
| Endpoint RPC          | `https://mainnet.base.org`           | `https://sepolia.base.org`                           |
| chain ID          | `8453`                               | `84532`                                              |
| Moneda                | ETH                                  | ETH                                                  |
| Explorador de bloques | [basescan.org](https://basescan.org) | [sepolia.basescan.org](https://sepolia.basescan.org) |
