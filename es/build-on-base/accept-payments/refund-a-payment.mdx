Reembolsa total o parcialmente un cargo o una captura del protocolo antes de `refundExpiry`. El límite reembolsable se gestiona onchain y los reembolsos siempre se envían a `paymentInfo.payer`.

<Info>
  El flujo de pago de esta guía se basa en el [Commerce Payments Protocol](https://github.com/base/commerce-payments).
</Info>

## Financiar y enviar el reembolso {#fund-and-submit-the-refund}

Los fondos capturados ya han salido del depósito en garantía. El `OperatorRefundCollector` desplegado obtiene la liquidez de reposición de `paymentInfo.operator`, por lo que debes aprobarlo por el importe del reembolso antes de llamar a `refund`.

{/* sample: refund-payment-ts */}

```typescript TypeScript lines wrap expandable highlight={8-11,16-17,26-27}
export async function refundPayment(
  payment: StoredProtocolPayment,
  refundAmount: bigint,
) {
  const [, , refundableAmount] = await publicClient.readContract({
    address: AUTH_CAPTURE_ESCROW,
    abi: authCaptureEscrowAbi,
    functionName: "paymentState",
    args: [payment.paymentInfoHash],
  });
  if (refundAmount > refundableAmount) throw new Error("Refund exceeds captured amount");
  const approval = await publicClient.simulateContract({
    account,
    address: payment.paymentInfo.token,
    abi: refundApprovalAbi,
    functionName: "approve",
    args: [OPERATOR_REFUND_COLLECTOR, refundAmount],
  });
  const approvalHash = await walletClient.writeContract(approval.request);
  await publicClient.waitForTransactionReceipt({ hash: approvalHash, confirmations: 2 });

  const refund = await publicClient.simulateContract({
    account,
    address: AUTH_CAPTURE_ESCROW,
    abi: authCaptureEscrowAbi,
    functionName: "refund",
    args: [payment.paymentInfo, refundAmount, OPERATOR_REFUND_COLLECTOR, "0x"],
  });
  const hash = await walletClient.writeContract(refund.request);
  return publicClient.waitForTransactionReceipt({ hash, confirmations: 2 });
}
```

Cada cargo o captura incrementa `refundableAmount` en su importe bruto. Las comisiones no reducen ese límite. Cada reembolso lo reduce en el importe devuelto.

<Check>
  Antes de completar la devolución, verifica `PaymentRefunded(paymentInfoHash, amount, tokenCollector)`, la transferencia al pagador almacenado y el valor actualizado de `refundableAmount`.
</Check>

<Warning>
  Llevar la contabilidad de los reembolsos no equivale a disponer de liquidez para pagarlos. Los tokens debe aportarlos el operador u otra fuente autorizada de forma independiente. Nunca reutilices la autorización residual del pagador para financiar un reembolso.
</Warning>
