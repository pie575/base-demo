Un depósito transfiere fondos desde Base al libro mayor mediante el contrato `Portal`. El activo, el importe y el remitente se liquidan públicamente en Base, pero el destinatario está cifrado, de modo que no es posible vincular entre sí varios depósitos a una misma cuenta. Consulta [Transacciones privadas](/es/get-started/private-transactions).

## Qué se expone onchain {#whats-exposed-onchain}

| Dato         | ¿Público? | Motivo                                                                                 |
| ------------ | --------- | -------------------------------------------------------------------------------------- |
| Activo       | Público   | El Portal liquida la transferencia en Base.                                            |
| Importe      | Público   | El Portal liquida la transferencia en Base.                                            |
| Remitente    | Público   | La dirección que envía el depósito.                                                    |
| Destinatario | Oculto    | Se cifra para que los depósitos a una misma cuenta no puedan vincularse ni atribuirse. |

Un depósito también puede requerir una atestación o un permiso, por ejemplo, para restringir quién puede depositar.
