Usa la atribución cuando necesites identificar qué builder generó una actividad onchain o determinar si un usuario cumple un requisito de elegibilidad verificado. Builder Codes y Base Verify resuelven aspectos distintos de ese problema.

## Atribuir la actividad onchain {#attribute-onchain-activity}

Los Builder Codes añaden un sufijo de atribución ERC-8021 al calldata de las transacciones. Los indexadores offchain utilizan este sufijo para vincular la actividad con la aplicación, la billetera o el agente que la generó.

## Verificar atributos de usuario {#verify-user-attributes}

Base Verify permite que un usuario demuestre que controla una cuenta compatible y que tu aplicación evalúe rasgos aprobados. Elige el flujo de backend para experiencias controladas por la aplicación, o el flujo onchain cuando un contrato inteligente deba hacer cumplir la política.

  </Card>

<Note>
  Los Builder Codes atribuyen el origen de las transacciones, pero no verifican la identidad ni la elegibilidad de un usuario. Base Verify evalúa atributos verificados de los usuarios, pero no atribuye las transacciones al builder que las generó.
</Note>
