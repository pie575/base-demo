アプリケーションの要件に合った SDK、API、コマンドラインツールを選択してください。Base では、本人確認 API、ローカル開発ツール、チェーンに直接アクセスできる API を提供しています。

<CardGroup cols={2}>
  <Card title="Base Chain API" icon="server" href="/ja/base-chain/api-reference/rpc-overview">
    Base ノードに対して JSON-RPC、Flashblocks ストリーミング、Debug トレースを利用できます。
  </Card>

  <Card title="Base Verify API" icon="user-check" href="/ja/sdks/base-verify/overview">
    検証済みアカウントの所有権を証明し、シビル攻撃に強い参加資格ポリシーを適用します。
  </Card>

  <Card title="base-anvil CLI" icon="terminal" href="/ja/sdks/base-anvil">
    Base の Foundry ツールチェーンで、Base ネイティブのコントラクトをローカルで構築・テストできます。
  </Card>
</CardGroup>

## どのインターフェースを使うべきか {#which-surface-do-i-need}

| 目的                                    | 使用するもの                                                                                |
| ------------------------------------- | ------------------------------------------------------------------------------------- |
| アカウントの所有権を検証する、または本人確認ポリシーを適用する       | [Base Verify API](/ja/sdks/base-verify/overview)                                         |
| Base ネイティブのコントラクトをローカルで構築・テストする       | [base-anvil CLI](/ja/sdks/base-anvil)                                                    |
| 残高、ブロック、ログを読み取る、または raw トランザクションを送信する | [Ethereum JSON-RPC](/ja/base-chain/api-reference/rpc-overview)                           |
| 1 秒未満の確認をストリーミングで受け取る                 | [Flashblocks API](/ja/base-chain/api-reference/flashblocks-api/flashblocks-api-overview) |
| トランザクションやブロックをトレースする                  | [Debug API](/ja/base-chain/api-reference/debug-api/debug_traceTransaction)               |
