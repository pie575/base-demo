Base Account SDK と Base MCP のドキュメントは、Base のドキュメントから [Coinbase Developer Platform](https://docs.cdp.coinbase.com) に移転しました。移転後のドキュメントは、唯一の正式な情報源 (Single Source of Truth) として同サイトで管理されています。

## 移行先のドキュメント {#find-the-migrated-documentation}

  <Card title="Coinbase Wallet SDK" icon="wallet" href="https://docs.cdp.coinbase.com/coinbase-wallet/overview">
    以前 Base ドキュメントで Base Account SDK として公開されていた SDK ドキュメントは、こちらで引き続きご覧いただけます。
  </Card>

  <Card title="Wallet MCP" icon="robot" href="https://docs.cdp.coinbase.com/ai-agents/coinbase-for-agents/wallet-mcp">
    以前 Base ドキュメントで Base MCP として公開されていた AI ウォレットのドキュメントは、こちらで引き続きご覧いただけます。
  </Card>
</CardGroup>

## 変更点 {#what-changed}

| Base ドキュメントでの旧名称 | Coinbase Developer Platform での名称 | 対応方法                                                                                                   |
| ---------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| Base Account SDK | Coinbase Wallet SDK              | [Coinbase Wallet SDK のドキュメント](https://docs.cdp.coinbase.com/coinbase-wallet/overview)を参照してください。        |
| Base MCP         | Wallet MCP                       | [Wallet MCP のドキュメント](https://docs.cdp.coinbase.com/ai-agents/coinbase-for-agents/wallet-mcp)を参照してください。 |
