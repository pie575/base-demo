公開されている Tokenized Stocks API を使用すると、[Base 上で Coinbase が発行するトークン化株式](/ja/build-on-base/integrate-defi/list-tokenized-stocks)の参照データを取得できます。この API は読み取り専用で、API キーは不要です。

<Note>
  Coinbase のトークン化株式は、米国外の対象法域に所在する方のみご利用いただけます。この API が提供するのは読み取り専用の参照データのみであり、取引、執行、発行、ミント、償還、カストディの機能は提供していません。トークンや関連製品を利用できるかどうかは、法域、適格性、コンプライアンス上の要件によって制限される場合があります。該当する制限の適用は、インテグレーターの責任で行ってください。
</Note>

```text Base URL
https://api.coinbase.com/v1/tokenized-stocks
```

リクエストおよびレスポンスの完全なスキーマと、インタラクティブなリクエストビルダーについては、[API リファレンス](/ja/sdks/tokenized-stocks/api-reference/list-tokenized-stocks)をご覧ください。

## エンドポイント {#endpoints}

| メソッド  | パス                                 | 説明                                           |
| ----- | ---------------------------------- | -------------------------------------------- |
| `GET` | `/`                                | API で現在公開されているトークン化株式のレコードを一覧表示します。          |
| `GET` | `/chains`                          | サポート対象の各チェーン上にあるトークン化株式プロトコルのコントラクトを一覧表示します。 |
| `GET` | `/total-supply/{contract_address}` | トークンの総供給量を、小数点以下桁数 (decimals) で正規化した値で取得します。           |

## トークン化株式の一覧を取得する {#list-tokenized-stocks}

```bash cURL
curl https://api.coinbase.com/v1/tokenized-stocks
```

レスポンスには、各トークンのコントラクトアドレス、シンボル、名前、小数点以下桁数 (decimals) 、アイコン URL、総供給量、ISIN、乗数 (multiplier) 、一時停止中の機能、NAV／参照値データが含まれます。レスポンスに含まれているからといって、取引が可能であることや、取引の対象となる資格があることを意味するものではありません。

## レスポンスフィールドの解釈 {#interpreting-response-fields}

* **`total_supply`** は、トークンの小数点以下桁数 (decimals) で正規化されたトークン供給量です。これはトークン単位の数量であり、原資産となる株式の数ではありません。
* **`multiplier`** は、トークン単位と原資産株式との間の現在の換算係数です。配当や株式分割などのコーポレートアクションによって変わることがあるため、トークン単位を株式数に換算する際は、必ず最新の値を使用してください。
* **`nav_price`** は、そのトークンについて直近に公表された Chainlink ベースの NAV／参照値です。リアルタイムの売買気配値や約定価格ではありません。
* **`nav_price_updated_at`** は、`nav_price` がオンチェーンで最後に更新された時刻です。フィードは価格乖離の発生時またはハートビート時にのみ更新され、取引時間外は最後の値が保持されます。そのため、`nav_price` を利用する前にこのタイムスタンプを確認し、データ鮮度の許容範囲 (staleness bounds) を適用してください。

統合に関するガイダンス、価格フィードの詳細、最新のトークンコントラクトアドレスについては、[トークン化株式の一覧を取得する](/ja/build-on-base/integrate-defi/list-tokenized-stocks) を参照してください。
