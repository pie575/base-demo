Vibenetは、Baseの実験的なプレビューネットワークです。新しいチェーンレベルの機能は、SepoliaやMainnetに展開される前に、まずこのdevnetで公開されます。Vibenetを使って、Baseの最先端の機能を活用した開発を進めましょう。

<Warning>
  Vibenetは実験専用のネットワークです。本番環境やユーザー向けアプリケーションでの利用は想定されておらず、ネットワークの状態は予告なくリセットされる場合があります。
</Warning>

## Vibenet で公開中の機能を確認する {#see-whats-live-on-vibenet}

[chain.base.org/vibenet](https://chain.base.org/vibenet) は Vibenet のハブです。リリースされる最新機能をチェックしたり、ブロックエクスプローラーを閲覧したり、フォーセットでテストネット ETH をリクエストしたりできます。

<Note>
  埋め込みコンテンツが読み込まれない場合は、[chain.base.org/vibenet](https://chain.base.org/vibenet) を新しいタブで直接開いてください。
</Note>

## テストネット ETH を入手する {#get-testnet-eth}

Vibenet のトランザクションにはガスが必要です。[Vibenet フォーセット](https://chain.base.org/vibenet/faucet)からテストネット ETH をリクエストするか、以下のようにプログラムから取得します。

```bash Terminal
curl -X POST https://api.vibes.base.org/api/vibenet/faucet/drip \
  -H "content-type: application/json" \
  -d '{"address":"0xYourAddress"}'
```

## WebSocket でストリーミングする {#stream-with-websockets}

Vibenet は公開 WebSocket エンドポイント `wss://rpc.vibes.base.org/ws` を提供しています。ポーリングする代わりに、`eth_subscribe` でサブスクライブすれば、更新をプッシュで受け取れます。

* **`newHeads`** — ブロックごとに新しいイベントが発行されます。チェーンやブロックの状態を追跡する場合に使用します。
* **`logs`** — アドレスとインデックス付きトピックでフィルタリングされたコントラクトイベントです。アプリケーションの状態を追跡する場合に使用します。

```javascript newHeads subscription lines wrap expandable
import WebSocket from "ws";

const ws = new WebSocket("wss://rpc.vibes.base.org/ws");

ws.on("open", () => {
  ws.send(JSON.stringify({
    jsonrpc: "2.0",
    id: 1,
    method: "eth_subscribe",
    params: ["newHeads"],
  }));
});

ws.on("message", (data) => {
  const msg = JSON.parse(data.toString());
  if (msg.method === "eth_subscription") {
    console.log("new head:", msg.params.result.number);
  }
});
```

ブロック間隔が200msの場合、250〜1000msのポーリングでは複数のブロックを取りこぼす可能性があるため、WebSocketによるプッシュを主なデータソースとしてください。長時間維持する接続は少数に抑え、サブスクリプションと通常のJSON-RPC呼び出しは1つの接続上で多重化します。ポーリングは整合性の確認 (残高、手数料、ヘルスチェック) に限って使用してください。また、ソケットが切断された場合に備えて、HTTPSによるRPC呼び出し経路をフォールバックとして用意しておいてください。

<Note>
  このパブリックWebSocketはVibenet専用です。BaseはBase MainnetおよびBase Sepolia向けに無料のパブリックWebSocket RPCエンドポイントを提供しておらず、これらのネットワークのパブリックエンドポイントはHTTPのみに対応しています。SepoliaまたはMainnetでWebSocketを利用するには、独自のノードを運用するか、[Builder Stack](/ja/get-started/builder-stack)に掲載されているWebSocket対応のプロバイダーを利用してください。
</Note>
