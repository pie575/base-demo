インシデント発生時には、発行や取り消しを止めずに `TRANSFER` 機能だけを一時停止できます。B20 では一時停止と再開の権限が別々のロールに付与されるため、緊急対応の権限と復旧の権限を分離できます。

## 株式トークンの転送の一時停止と再開 {#pause-and-resume-stock-transfers}

<CodeGroup>
  {/* sample: stock-pause-ts */}

  ```typescript TypeScript lines wrap expandable highlight={7}
  import { type Address } from "viem";
  import { publicClient } from "../../shared/clients.js";
  import { b20Abi } from "../abi.js";
  import { sendContract } from "../write.js";

  export async function setStockTransfersPaused(token: Address, paused: boolean) {
    await sendContract({ address: token, abi: b20Abi, functionName: paused ? "pause" : "unpause", args: [[0]] });
    const current = await publicClient.readContract({ address: token, abi: b20Abi, functionName: "isPaused", args: [0] });
    if (current !== paused) throw new Error("Unexpected transfer pause state");
  }
  ```

  {/* sample: stock-pause-cli */}

  ```bash CLI lines wrap expandable highlight={1,4}
  base-cast send "$TOKEN_ADDRESS" "pause(uint8[])" "[0]" \
    --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY"
  base-cast call "$TOKEN_ADDRESS" "isPaused(uint8)(bool)" 0 --rpc-url "$RPC_URL"
  base-cast send "$TOKEN_ADDRESS" "unpause(uint8[])" "[0]" \
    --rpc-url "$RPC_URL" --private-key "$PRIVATE_KEY"
  ```
</CodeGroup>

`pause` と `unpause` はいずれも `PausableFeature[]` 配列を引数に取ります。`TRANSFER` だけを対象にするには `[0]` を渡します。一時停止できる機能は `TRANSFER` (0)、`MINT` (1)、`BURN` (2)、`SEIZE` (3) の4つです。ある機能を一時停止しても、他の機能には影響しません。`MINT` の一時停止中も保有者は転送でき、`TRANSFER` の一時停止中もミンターはミントできます。

空の配列を渡すと `EmptyFeatureSet` でリバートします。すでに指定した状態になっている機能に対しては何も行われず、呼び出しもリバートしません。呼び出し後は `isPaused(feature)` を読み取って現在の状態を確認してください。発行されるイベント (`Paused` または `Unpaused`) に含まれるのは渡した配列そのものであり、結果として一時停止中となった機能の集合ではありません。

一時停止中の機能に対応する操作を呼び出し元が実行しようとすると、呼び出しは `ContractPaused(feature)` でリバートします。

<Check>
  ミントやバーンは一時停止されず、転送の一時停止状態だけが変更されます。
</Check>

<Note>
  `pause` には `PAUSE_ROLE` が、`unpause` には `UNPAUSE_ROLE` が必要です。両者は別々のロールであるため、復旧の権限は緊急停止の権限よりも対象を絞って付与してください。
</Note>
