Base ネイティブの標準を使って構築することも、ネットワーク上にデプロイ済みのプロトコルを統合することもできます。実現したい金融上の目的を選び、プロダクトで行う具体的な操作に応じた簡潔なガイドに沿って進めてください。

## ソリューション {#solutions}

<CardGroup cols={2}>
  <Card title="DeFi を統合する" icon="scale-balanced" href="/ja/get-started/integrate-defi">
    トレード、直接貸付、担保付き借入、ボールト型の運用プロダクトを追加できます。
  </Card>

  <Card title="資産をトークン化する" icon="building-columns" href="/ja/get-started/issue-rwa">
    B20 Asset の発行、保有者管理、分配機能を活用して、現実資産をトークンとして表現します。
  </Card>

  <Card title="ステーブルコインを発行する" icon="coins" href="/ja/get-started/issue-stablecoins">
    ミント、コンプライアンス、照合の機能を標準搭載した法定通貨担保型トークンをローンチできます。
  </Card>

  <Card title="決済を受け付ける" icon="credit-card" href="/ja/get-started/accept-payments">
    請求、承認、売上確定、検証、返金、照合、支払いまで、決済のライフサイクル全体を構築できます。
  </Card>

  <Card title="プライベートトランザクション" icon="shield-halved" href="/ja/get-started/private-transactions">
    Base Ledgers を使って、機密性を保ったままオンチェーンで決済できます。
  </Card>

  <Card title="Vibenet でテストする" icon="flask" href="/ja/build-on-base/test-on-vibenet">
    使い捨てのフル機能テストネットワークで、あらゆる機能を試せます。
  </Card>
</CardGroup>
