資金は、Base 上の `Portal` コントラクトを通じてレジャーから出金されます。Portal による出金の検証方法 (署名チェックから完全な状態遷移証明まで) は自由に選択でき、その背後にあるアカウントは非公開のままとなるため、入金と出金が紐付けられることはありません。詳しくは [Private Transactions](/ja/get-started/private-transactions) を参照してください。

## オンチェーンで公開される情報 {#whats-exposed-onchain}

| データ  | 公開の有無 | 理由                     |
| ---- | ----- | ---------------------- |
| アセット | 公開    | Base での決済に必要なため。       |
| 金額   | 公開    | Base での決済に必要なため。       |
| 送信者  | 非公開   | レジャーの Portal では開示されないため。 |
| 受信者  | 公開    | Base での決済に必要なため。       |

`withdraw()` は通常の Base コントラクト呼び出しであるため、他の Base 上の操作とまとめて 1 つのアトミックなトランザクションとして実行できます。これらの操作はすべてまとめて決済されるか、いずれも決済されないかのどちらかです。
