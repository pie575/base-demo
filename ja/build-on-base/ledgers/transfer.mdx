資金を台帳に入金すると、アカウントは残高やアクティビティを公開のブロックエクスプローラーに表示させることなく、送金、スワップ、利回りの獲得を行えます。Base 上で処理されるのは入金と出金のみで、その間の処理はすべて非公開です。詳しくは[プライベートトランザクション](/ja/get-started/private-transactions)を参照してください。

## オンチェーンで公開される情報 {#whats-exposed-onchain}

| データ     | 公開有無 | 理由                          |
| ------- | ---- | --------------------------- |
| 送信者     | 非公開  | 送金は台帳内で完結します。               |
| 受信者     | 非公開  | 送金は台帳内で完結します。               |
| 金額      | 非公開  | 送金は台帳内で完結します。               |
| アクティビティ | 非公開  | 送金に関する情報は一切 Base 上に記録されません。 |

台帳は背後にあるオフチェーンシステムの種類を問わないため、独自の帳簿管理やカスタムのトランザクションロジックを自由に運用できます。
