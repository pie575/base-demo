## 概要 {#overview}

L1 ブロック属性トランザクションが更新され、DA フットプリントガススカラーが含まれるようになりました。

| 入力引数                 | 型       | Calldata バイト | セグメント |
| -------------------- | ------- | ------------ | ----- |
| {0x3db6be2b}         |         | 0-3          | n/a   |
| baseFeeScalar        | uint32  | 4-7          | 1     |
| blobBaseFeeScalar    | uint32  | 8-11         |       |
| sequenceNumber       | uint64  | 12-19        |       |
| l1BlockTimestamp     | uint64  | 20-27        |       |
| l1BlockNumber        | uint64  | 28-35        |       |
| basefee              | uint256 | 36-67        | 2     |
| blobBaseFee          | uint256 | 68-99        | 3     |
| l1BlockHash          | bytes32 | 100-131      | 4     |
| batcherHash          | bytes32 | 132-163      | 5     |
| operatorFeeScalar    | uint32  | 164-167      | 6     |
| operatorFeeConstant  | uint64  | 168-175      |       |
| daFootprintGasScalar | uint16  | 176-177      |       |

以前のバージョンの L1 属性トランザクションと同様に、最初の入力引数は関数セレクタ、
すなわち `keccak256("setL1BlockValuesJovian()")` の先頭 4 バイトである点に注意してください。

有効化ブロックについては、次の 2 つのケースがあります。

* Jovian がジェネシス時点で有効な場合、有効化ブロックにはトランザクションが存在しないため、
  L1 ブロック属性トランザクションを考慮する必要はありません。
* Jovian がジェネシス後に有効化される場合は、[`setL1BlockValuesIsthmus()`](../isthmus/l1-attributes) メソッドを使用しなければなりません。
  これは、L1 Block コントラクトがまだアップグレードされていないためです。

以降の各 L2 ブロックでは、`setL1BlockValuesJovian()` メソッドを使用しなければなりません。

このメソッドを使用する場合、Jovian 以前の値はそのまま 1:1 で引き継がれ、
さらにトランザクションによって `daFootprintGasScalar` が
[`SystemConfig`](/ja/specifications/base-protocol/consensus/derivation#system-configuration) の値に設定されます。その値が `0` の場合は、デフォルト値の `400` が設定されます。
