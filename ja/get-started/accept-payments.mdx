プロダクトに必要なライフサイクルに合わせて、Base で決済を受け付けましょう。[Commerce Payments Protocol](https://github.com/base/commerce-payments) を使えば、即時に課金することも、フルフィルメント前に資金をエスクローで確保しておくこともできます。その後、支払者が承認した条件のもとで、キャプチャ、取り消し (void) 、回収 (reclaim) 、返金を実行できます。このソリューション領域では、スケジュールに基づく集金、照合、ペイアウト、分配 (スプリット) 、x402 API も扱います。

## 支払いのライフサイクル {#payment-lifecycle}

| ステージ                 | 処理内容                                    | 参照先                                                                     |
| -------------------- | --------------------------------------- | ----------------------------------------------------------------------- |
| Charge               | オペレーターがプロトコル上の支払いの回収と決済をアトミックに行います      | [支払いをリクエストする](/ja/build-on-base/accept-payments/request-a-payment)         |
| Authorize            | オペレーターが支払者の資金をエスクローに移します                | [支払いをオーソリする](/ja/build-on-base/accept-payments/authorize-a-payment)        |
| Capture              | オペレーターがエスクロー中の金額の全額または一部を決済します          | [オーソリをキャプチャする](/ja/build-on-base/accept-payments/capture-an-authorization) |
| Confirm              | バックエンドが確定済みのプロトコルイベントを検証し、注文を一度だけ確定させます | [支払いを検証する](/ja/build-on-base/accept-payments/verify-a-payment)             |
| Return or distribute | 支払者に返金するか、下流の受取人に支払います                  | [支払いを返金する](/ja/build-on-base/accept-payments/refund-a-payment)             |
