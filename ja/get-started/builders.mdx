## 構築 {#build}

### ドキュメント {#documentation}

オンチェーン開発を始めるために必要な[基礎知識](/ja/get-started/base)を学びましょう。

### Builder Codes {#builder-codes}

Base チームによる助成金の提供は、厳選された案件に限られています。助成金の対象となるには、まず Builder Codes を統合する必要があります。

Builder Codes は、アプリのトランザクションにタグを付ける一意の識別子です。これにより、Base はオンチェーンのアクティビティがあなたのアプリによるものであることを把握できます。確実にセットアップを済ませておきましょう。

<a className="view-features-btn button-white" href="/ja/specifications/builder-codes/overview">詳細を見る</a>

### クエスト {#quests}

学んだことを活かせる課題に挑戦してみませんか？

Builder Quests は、Base がビルダーコミュニティに向けて定期的に開催しているチャレンジです。テーマを選んで実際に動くものを作り、報酬を獲得しましょう。クエストの最新情報は、Build on Base の X アカウントをフォローしてご確認ください。

<a className="view-features-btn button-white" href="https://x.com/buildonbase">詳細を見る</a>

## サポート {#support}

### Builder Stack {#builder-stack}

Builder Stack は、これらをひとつにまとめたパッケージです。LLM 推論やクラウドをはじめとする開発インフラ向けのツールとクレジットをまとめて提供しており、Builder Grant Program に採択されたチームが利用できます。

<a className="view-features-btn button-white" href="/ja/get-started/base-services-hub">詳細を見る</a>

### 地域別の情報発信支援 {#regional-amplification}

Base上で積極的に開発を進め、成果を上げているプロジェクトの皆さまを、情報発信の面でぜひサポートさせてください。

ベストプラクティスについては、情報発信に関する[ガイドライン](https://github.com/base-org/brand-kit/blob/main/guides/editorial-style-guide.md#what-to-avoid)をご確認ください。

新しいプロダクトや機能、メジャーリリースをローンチする際は、Baseの地域コミュニティアカウントを通じて発信し、皆さまをサポートします。これらのアカウントは、LATAM、APAC、ヨーロッパ、アフリカ、インド、ブラジルにまたがり、合計10万人以上のコミュニティを擁しています。

<a className="view-features-btn button-white" href="https://forms.gle/q852YTA83eUTFyz37">応募する</a>

### Baseposting による紹介 {#baseposting-coverage}

Baseposting では、Base エコシステムのニュースやアップデートを毎日発信しています。すべてのプロジェクトを紹介できるとは限りませんが、紹介を希望する場合は、重要なアップデートを伝える投稿で [@baseposting](https://x.com/baseposting) をタグ付けするのが最も確実です。

### Builder Call {#builder-call}

四半期に2回、[Base Builder Call](https://x.com/base/status/2085381551437570256?s=20)を開催し、プロダクト、ビルダー、コミュニティなど、さまざまな観点からBaseエコシステムの現状について話し合っています。

次回のコールで自分のプロジェクトを取り上げてほしい場合は、Baseで構築しているものの簡単な説明を添えて、Xで@AhaanRaizadaをタグ付けしてください。

### ラウンドテーブル {#roundtables}

毎週木曜日の午後1時30分 (米国東部時間) に、その週のトピックをテーマにした Builder Roundtable X Space を開催しており、Base のビルダーをスピーカーとしてお招きしています。次回の参加にご興味がある方は、X で @saxenasaheb または @AhaanRaizada に DM をお送りください。

## 資金を獲得する {#get-funded}

### 助成金プログラム {#grant-program}

以下の分野で Base 上での開発に積極的に取り組んでいるプロジェクトを対象に、最大 5,000 ドルの助成金に加え、GTM およびプロダクト面でのサポートを提供します。

1. 予測市場
2. トークンローンチパッド
3. DeFi 2.0 — レンディング、借入、ルーピング、利回り創出、ボールト、トークン化株式
4. エージェント — コマース、x402 の実装、自律型トレーディング
5. 新たな資産の創出に注力するプロダクト
6. トランザクションの拡大に注力するコンシューマー向けアプリ

次期コホートへの参加をぜひお申し込みください。

<a className="view-features-btn button-white" href="https://forms.gle/urqjBJYJjR6Vqqre6">申し込む</a>

### Base Batches {#base-batches}

Base Batches は、Base 上で金融の未来を築くアーリーステージのチームを対象としたアクセラレーターで、Base Ecosystem Fund が運営しています。各コホートは短期間のオンラインプログラムで、最後に投資家の前でデモデイを行います。

<a className="view-features-btn button-white" href="https://www.base.org/batches">応募する</a>

### Base Ecosystem Fund {#base-ecosystem-fund}

Base Ecosystem Fundは、Coinbase Venturesと共同で運営されているBaseの戦略的投資部門です。Base上でオンチェーンビジネスを構築するアーリーステージのチームを支援しています。

<a className="view-features-btn button-white" href="https://www.base.org/ecosystem-fund">応募する</a>
