## クリエイター助成プログラム {#creator-grant-program}

Base に関する優れたコンテンツをすでに発信している個人クリエイターを、最大 $4,000 で支援します。対象となるのは次のようなクリエイターです。

1. Base について執筆するライター (詳細解説、ミーム、分析、スレッドなど) 
2. ストリーマーおよびライブ配信のホスト
3. ポッドキャストや番組を定期的に配信しているクリエイター
4. 個人の動画クリエイター
5. 自身の母語で Base について発信している教育者
