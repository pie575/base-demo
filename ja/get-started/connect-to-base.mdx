Base は標準的な EVM チェーンのため、Ethereum 向けのツール、ウォレット、ライブラリはどれも変更なしでそのまま動作します。以下のネットワーク情報を設定するだけで利用できます。

## ネットワークの詳細 {#network-details}

|              | Base Mainnet                         | Base Sepolia (テストネット)                                |
| ------------ | ------------------------------------ | ---------------------------------------------------- |
| RPC エンドポイント  | `https://mainnet.base.org`           | `https://sepolia.base.org`                           |
| チェーン ID      | `8453`                               | `84532`                                              |
| 通貨           | ETH                                  | ETH                                                  |
| ブロックエクスプローラー | [basescan.org](https://basescan.org) | [sepolia.basescan.org](https://sepolia.basescan.org) |
