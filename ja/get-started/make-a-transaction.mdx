Base は Ethereum と同じトランザクションモデルを採用しているため、どの EVM ライブラリでも利用できます。ここでは [viem](https://viem.sh) を使った最小限の送信例を紹介します。

## トランザクションを送信する {#send-a-transaction}

```ts send.ts lines wrap expandable
import { createWalletClient, http, parseEther } from 'viem';
import { privateKeyToAccount } from 'viem/accounts';
import { base } from 'viem/chains';

const account = privateKeyToAccount('0xYourPrivateKey');

const client = createWalletClient({
  account,
  chain: base,
  transport: http('https://mainnet.base.org'),
});

const hash = await client.sendTransaction({
  to: '0xRecipientAddress',
  value: parseEther('0.001'),
});

console.log(`Sent, view at https://basescan.org/tx/${hash}`);
```

<Warning>
  秘密鍵は絶対にハードコードしたり公開したりしないでください。`'0xYourPrivateKey'` はプレースホルダーです。鍵は環境変数またはシークレットマネージャーから読み込み、サーバー側で保持してください。また、ソース管理には決してコミットしないでください。
</Warning>

<Tip>
  Base では [Flashblocks](/ja/specifications/transactions/transaction-ordering#flashblocks) により、トランザクションは 1 秒未満で承認されます。ガス代も通常は 1 セントに満たないわずかな額です。
</Tip>
