現在の事前確認済み Flashblock の状態に対して、1 つ以上のトランザクションバンドルをシミュレートします。状態オーバーライド、複数ブロックのシミュレーション、および転送トレース (オプション) に対応しています。

<Info>
  Flashblocks エンドポイント (`https://mainnet.base.org` / `https://sepolia.base.org`) でのみ利用できます。
</Info>

## パラメーター {#parameters}

<ParamField body="simulationPayload" type="object" required>
  シミュレーションの設定です。

  <Expandable title="Simulation Payload のフィールド">
    <ParamField body="blockStateCalls" type="array" required>
      ブロック状態呼び出しオブジェクトの配列です。各オブジェクトが、シミュレートする 1 つのブロックに対応します。

      <Expandable title="Block State Call のフィールド">
        <ParamField body="calls" type="array">
          このブロック内でシミュレートするトランザクション呼び出しオブジェクトの配列です。
        </ParamField>

        <ParamField body="stateOverrides" type="object">
          シミュレーション前に適用する、アドレスごとの状態オーバーライドです (例：残高、nonce、コード、ストレージ) 。省略可能です。
        </ParamField>

        <ParamField body="blockOverrides" type="object">
          ブロックレベルのオーバーライドです (例：`number`、`timestamp`) 。省略可能です。
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="traceTransfers" type="boolean">
      `true` の場合、ETH の送金イベントがログとして結果に含まれます。デフォルトは `false` です。
    </ParamField>

    <ParamField body="validation" type="boolean">
      `true` の場合、トランザクションの検証 (nonce、残高) が行われます。デフォルトは `false` です。
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="blockParameter" type="string" required>
  現在の Flashblock の状態に対してシミュレートするには、`"pending"` を指定します。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="array">
  シミュレートされたブロック結果の配列です。`blockStateCalls` のエントリごとに 1 つずつ返されます。各エントリは完全なブロックオブジェクトで、標準のブロックフィールドに加えて `calls` フィールドが埋め込まれています。

  <Expandable title="ブロック結果のフィールド">
    <ResponseField name="number" type="string">シミュレートされたブロック番号 (16 進数) 。</ResponseField>
    <ResponseField name="hash" type="string">シミュレートされたブロックハッシュ。</ResponseField>
    <ResponseField name="parentHash" type="string">親ブロックのハッシュ。</ResponseField>
    <ResponseField name="timestamp" type="string">ブロックのタイムスタンプ (16 進数) 。</ResponseField>
    <ResponseField name="gasLimit" type="string">ガスリミット (16 進数) 。</ResponseField>
    <ResponseField name="gasUsed" type="string">シミュレートされた呼び出しで使用されたガスの合計 (16 進数) 。</ResponseField>
    <ResponseField name="baseFeePerGas" type="string">ガスあたりの基本手数料 (16 進数) 。</ResponseField>
    <ResponseField name="stateRoot" type="string">常に `"0x000...000"` です。シミュレーションでは状態がトライにコミットされないためです。</ResponseField>

    <ResponseField name="calls" type="array">
      個々の呼び出し結果の配列。

      <Expandable title="呼び出し結果のフィールド">
        <ResponseField name="status" type="string">成功時は `"0x1"`、失敗時は `"0x0"`。</ResponseField>
        <ResponseField name="gasUsed" type="string">使用されたガス (16 進整数) 。</ResponseField>
        <ResponseField name="returnData" type="string">16 進エンコードされた戻りデータ。</ResponseField>
        <ResponseField name="logs" type="array">発行されたログ (`traceTransfers` が `true` の場合は ETH 送金ログも含む) 。</ResponseField>
        <ResponseField name="error" type="string">呼び出しが失敗した場合のリバート理由。省略可能。</ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
</ResponseField>
