`eth_subscribe` でサブスクライブすると、トランザクションが Flashblock にプレコンファームされるたびに、各トランザクションを受信できます。2 番目のパラメーターに `true` を渡すと、トランザクションとレシートの完全なデータを受信できます。

<Info>
  このサブスクリプションを利用するには、WebSocket に対応した RPC エンドポイントが必要です。Base の公開エンドポイント (`mainnet.base.org`、`sepolia.base.org`) は HTTP にのみ対応しています。[Builder Stack](/ja/get-started/builder-stack) から WebSocket 対応のプロバイダーを選択してください。
</Info>

<Note>
  [base/base](https://github.com/base/base) クライアントのバージョン v0.8.0 以上が必要です。
</Note>

<Warning>
  各サブスクリプションは、**WebSocket メッセージ 1 件につき 1 項目**を送信します。イベントは約 200ms ごとに届きます。ハンドラーでイベントごとに重い処理を行う場合は、ブロッキングを避けるためにスロットリングまたはデバウンスを適用してください。
</Warning>

## パラメーター {#parameters}

<ParamField body="subscriptionType" type="string" required>
  `"newFlashblockTransactions"` を指定する必要があります。
</ParamField>

<ParamField body="full" type="boolean">
  `true` の場合、各通知にはレシートのフィールドを含む完全なトランザクションオブジェクトが含まれます。デフォルトは `false` (トランザクションハッシュのみ) です。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="string">
  サブスクライブ時に返される、16進数エンコードされたサブスクリプション ID。
</ResponseField>

## 通知 {#notifications}

各通知は標準的な `eth_subscription` メッセージです。`params.result` フィールドの内容は `full` パラメーターによって異なります。

**`full: false`** — `result` はトランザクションハッシュです：

```json Result (full: false)
"0xe26de91f9037e903eefe70b28f613019253da603e67e0dbfe2f656dce5444311"
```

**`full: true`** — `result` は、レシートのフィールドが直接埋め込まれたトランザクションオブジェクトです (レシートはサブオブジェクトとしてネストされません) 。`base/v0.9.0` の実環境で検証済みです：

<ResponseField name="type" type="string">トランザクションタイプ：`0x0` Legacy、`0x2` EIP-1559、`0x7e` Deposit。</ResponseField>
<ResponseField name="chainId" type="string">チェーン ID (16 進数) 。</ResponseField>
<ResponseField name="nonce" type="string">送信者の nonce (16 進数) 。</ResponseField>
<ResponseField name="gas" type="string">ガスリミット (16 進数) 。</ResponseField>
<ResponseField name="maxFeePerGas" type="string">EIP-1559 のガスあたりの最大手数料 (16 進数) 。</ResponseField>
<ResponseField name="maxPriorityFeePerGas" type="string">EIP-1559 のガスあたりの最大優先手数料 (16 進数) 。</ResponseField>
<ResponseField name="to" type="string">受信者のアドレス。</ResponseField>
<ResponseField name="value" type="string">送金された ETH の額 (16 進数) 。</ResponseField>
<ResponseField name="accessList" type="array">EIP-2930 のアクセスリスト。</ResponseField>
<ResponseField name="input" type="string">トランザクションの入力データ (16 進数) 。</ResponseField>
<ResponseField name="r" type="string">署名の r 成分。</ResponseField>
<ResponseField name="s" type="string">署名の s 成分。</ResponseField>
<ResponseField name="yParity" type="string">署名のパリティ (16 進数) 。</ResponseField>
<ResponseField name="v" type="string">署名の v 値 (16 進数) 。</ResponseField>
<ResponseField name="hash" type="string">トランザクションハッシュ。</ResponseField>
<ResponseField name="blockHash" type="null">常に `null` です。トランザクションはプレコンファームの状態で、まだ確定済みのブロックには含まれていません。</ResponseField>
<ResponseField name="blockNumber" type="string">構築中の Flashblock のブロック番号 (16 進数) 。</ResponseField>
<ResponseField name="transactionIndex" type="string">ブロック内のインデックス (16 進数) 。</ResponseField>
<ResponseField name="from" type="string">送信者のアドレス。</ResponseField>
<ResponseField name="gasPrice" type="string">実効ガス価格 (16 進数) 。</ResponseField>
<ResponseField name="gasUsed" type="string">このトランザクションで使用されたガス量 (16 進数) 。**注意：** v0.8.0 で整数から 16 進数文字列に変更されました。</ResponseField>
<ResponseField name="status" type="string">成功時は `0x1`、失敗時は `0x0`。</ResponseField>
<ResponseField name="cumulativeGasUsed" type="string">ブロック内でこのトランザクションまで (このトランザクションを含む) に使用されたガスの合計 (16 進数) 。</ResponseField>
<ResponseField name="contractAddress" type="string | null">作成されたコントラクトのアドレス。作成されていない場合は `null`。</ResponseField>
<ResponseField name="logsBloom" type="string">ログのブルームフィルター (16 進数) 。</ResponseField>
<ResponseField name="logs" type="array">このトランザクションが発行したログオブジェクトの配列。</ResponseField>

<Warning>
  `gasUsed` は整数ではなく 16 進数文字列 (例：`"0x26132"`) です。この仕様は v0.8.0 で変更されました。数値を前提としているパーサーはすべて更新してください。
</Warning>
