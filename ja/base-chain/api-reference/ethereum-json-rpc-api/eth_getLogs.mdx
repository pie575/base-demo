title: 'eth_getLogs'
sidebarTitle: 'eth_getLogs'
description: 'フィルターに一致するログを返します。pending を指定すると、プレコンファーム済みトランザクションのログをクエリできます。'
---

指定したフィルターオブジェクトに一致するすべてのログを配列で返します。オンチェーンイベントのインデックス作成に特に便利です。

<Warning>
  広いブロック範囲にまたがるクエリや、アクティビティの多いコントラクトを対象とするクエリは、タイムアウトしたり拒否されたりすることがあります。安定した結果を得るには、`fromBlock` から `toBlock` までの範囲を 2,000 ブロック未満に抑えてください。また、ノードプロバイダーによっては独自の制限が設けられている場合があります。
</Warning>

<Tip>
  **Flashblocks:** `"fromBlock": "pending"` と `"toBlock": "pending"` を指定すると、約 200ms ごとに更新されるプレコンファーム済みトランザクションのログをクエリできます。リアルタイムのストリームが必要な場合は、代わりに [`pendingLogs`](/ja/base-chain/api-reference/flashblocks-api/pendingLogs) WebSocket サブスクリプションの利用を検討してください。
</Tip>

## パラメーター {#parameters}

<ParamField body="filter" type="object" required>
  フィルターオプション。少なくとも 1 つの条件を指定してください。

  <Expandable title="フィルターフィールド">
    <ParamField body="fromBlock" type="string">
      ブロック範囲の開始位置。16 進数のブロック番号またはブロックタグで指定します。プレコンファーム済みのログを含めるには `"pending"` を指定します。デフォルトは `"latest"` です。
    </ParamField>

    <ParamField body="toBlock" type="string">
      ブロック範囲の終了位置。16 進数のブロック番号またはブロックタグで指定します。デフォルトは `"latest"` です。
    </ParamField>

    <ParamField body="address" type="string | array">
      フィルター対象のコントラクトアドレス、またはアドレスの配列。省略可能です。
    </ParamField>

    <ParamField body="topics" type="array">
      32 バイトのトピックフィルターの配列。各位置には、`null` (任意の値に一致) 、単一トピックの 16 進数文字列、または 16 進数文字列の配列 (配列内のいずれかに一致) を指定できます。通常、位置 0 はイベントシグネチャの `keccak256` ハッシュです。省略可能です。
    </ParamField>

    <ParamField body="blockHash" type="string">
      このハッシュを持つブロックのログのみに絞り込みます。指定した場合、`fromBlock` と `toBlock` は無視されます。省略可能です。
    </ParamField>
  </Expandable>
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="array">
  フィルターに一致するログオブジェクトの配列。

  <Expandable title="ログオブジェクトのフィールド">
    <ResponseField name="address" type="string">ログを発行したコントラクトの20バイトのアドレス。</ResponseField>
    <ResponseField name="topics" type="array">インデックス付きの32バイトのトピック (0〜4個) の配列。通常、トピック0はイベントシグネチャのハッシュです。</ResponseField>
    <ResponseField name="data" type="string">インデックス化されていないイベントパラメータ (ABIエンコード済み) 。</ResponseField>
    <ResponseField name="blockNumber" type="string">このログが発行されたブロックの番号 (16進数) 。</ResponseField>
    <ResponseField name="blockTimestamp" type="string">このログを含むブロックのUnixタイムスタンプ (16進数文字列) 。標準のEthereumログスキーマに対するBase L2独自の拡張です。</ResponseField>
    <ResponseField name="transactionHash" type="string">このログを発行したトランザクションの32バイトのハッシュ。</ResponseField>
    <ResponseField name="transactionIndex" type="string">ブロック内でのトランザクションのインデックス (16進数) 。</ResponseField>
    <ResponseField name="blockHash" type="string">ブロックの32バイトのハッシュ。</ResponseField>
    <ResponseField name="logIndex" type="string">ブロック内でのログのインデックス位置 (16進数) 。</ResponseField>
    <ResponseField name="removed" type="boolean">チェーンの再編成 (reorg) によってログが削除された場合は`true`。</ResponseField>
  </Expandable>
</ResponseField>
