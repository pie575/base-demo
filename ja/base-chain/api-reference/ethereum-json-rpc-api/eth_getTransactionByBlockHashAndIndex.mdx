---

ブロックハッシュと、そのブロック内でのトランザクションのインデックス位置を指定して、該当するトランザクションの情報を返します。

## パラメーター {#parameters}

<ParamField body="blockHash" type="string" required>
  32バイトのブロックハッシュ。
</ParamField>

<ParamField body="index" type="string" required>
  トランザクションのインデックス位置 (16進数の整数) 。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="object | null">
  トランザクションオブジェクト。見つからない場合は `null` を返します。全フィールドの一覧については [`eth_getTransactionByHash`](/ja/base-chain/api-reference/ethereum-json-rpc-api/eth_getTransactionByHash) を参照してください。
</ResponseField>
