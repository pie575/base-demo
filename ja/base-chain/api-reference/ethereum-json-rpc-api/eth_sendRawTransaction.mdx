署名済みの RLP エンコードされたトランザクションをネットワークに送信し、そのハッシュを返します。

<Tip>
  **Flashblocks:** `https://mainnet.base.org` に送信すると、トランザクションは次の Flashblock (約 200ms) に含める候補となります。[`base_transactionStatus`](/ja/base-chain/api-reference/flashblocks-api/base_transactionStatus) でメモリプールへの到達を確認し、[`newFlashblockTransactions`](/ja/base-chain/api-reference/flashblocks-api/newFlashblockTransactions) をサブスクライブしてプレコンファメーションを検知してください。
</Tip>

## パラメーター {#parameters}

<ParamField body="data" type="string" required>
  RLP エンコードされた 16 進文字列形式の署名済みトランザクション。通常は viem、ethers.js、web3.js などのウォレットライブラリで生成します。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="string">
  トランザクションがメモリプールに受け入れられた場合は、32バイトのトランザクションハッシュを返します。
</ResponseField>

## エラーコード {#error-codes}

| コード      | メッセージ                                      | 説明                                             |
| -------- | ------------------------------------------ | ---------------------------------------------- |
| `-32000` | nonce too low                              | トランザクションの nonce が、アカウントの現在の nonce より小さくなっています。 |
| `-32000` | insufficient funds for gas * price + value | 送信者の残高が、ガス代と送金額の合計に足りません。                      |
| `-32000` | already known                              | 同一のトランザクションがすでにメモリプールに存在します。                   |
| `-32000` | replacement transaction underpriced        | 置き換えトランザクションでは、ガス価格を 10% 以上引き上げる必要があります。       |
