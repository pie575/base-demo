指定したブロック番号のブロックに関する情報を返します。

<Tip>
  **Flashblocks:** `https://mainnet.base.org` に `"pending"` を指定してクエリすると、構築中のライブ Flashblock を取得できます。これは実際のブロックオブジェクトで、新たに事前確認されたトランザクションを反映して約 200ms ごとに更新されます。レスポンスの形式は通常と同じで、ブロックがまだシールされていない点だけが異なります。
</Tip>

## パラメーター {#parameters}

<ParamField body="block" type="string" required>
  16進数のブロック番号、または `"latest"`、`"pending"`、`"safe"`、`"finalized"`、`"earliest"` のいずれか。生成中のブロックを取得するには `"pending"` を指定します。
</ParamField>

<ParamField body="fullTransactions" type="boolean" required>
  `true` の場合は完全なトランザクションオブジェクトを返し、`false` の場合はトランザクションハッシュのみを返します。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="object">
  ブロックオブジェクト。ブロックが見つからない場合は `null`。

  <Expandable title="ブロックのフィールド">
    <ResponseField name="number" type="string">ブロック番号 (16進数) 。pending の場合は `null`。</ResponseField>
    <ResponseField name="hash" type="string">ブロックハッシュ。pending の場合は `null`。</ResponseField>
    <ResponseField name="parentHash" type="string">親ブロックのハッシュ。</ResponseField>
    <ResponseField name="nonce" type="string">PoW の nonce。Base (PoS) では常に `"0x0000000000000000"`。</ResponseField>
    <ResponseField name="sha3Uncles" type="string">アンクルリストのハッシュ。Base では常に空。</ResponseField>
    <ResponseField name="logsBloom" type="string">ブロックのログのブルームフィルター。</ResponseField>
    <ResponseField name="transactionsRoot" type="string">トランザクショントライのルート。</ResponseField>
    <ResponseField name="stateRoot" type="string">最終的な状態トライのルート。</ResponseField>
    <ResponseField name="receiptsRoot" type="string">レシートトライのルート。</ResponseField>
    <ResponseField name="miner" type="string">手数料受取人 (coinbase) のアドレス。</ResponseField>
    <ResponseField name="difficulty" type="string">Base (PoS) では常に `"0x0"`。</ResponseField>
    <ResponseField name="mixHash" type="string">すべてのブロックに存在し、PoS コンセンサス用に転用されている (bytes32 の16進数) 。</ResponseField>
    <ResponseField name="extraData" type="string">シーケンサーが設定する任意のデータフィールド。</ResponseField>
    <ResponseField name="size" type="string">ブロックサイズ (バイト単位、16進数) 。</ResponseField>
    <ResponseField name="gasLimit" type="string">このブロックで許容される最大ガス量 (16進数) 。</ResponseField>
    <ResponseField name="gasUsed" type="string">このブロックで使用されたガスの合計 (16進数) 。</ResponseField>
    <ResponseField name="timestamp" type="string">Unix タイムスタンプ (16進数) 。</ResponseField>
    <ResponseField name="transactions" type="array">トランザクションハッシュ、または完全なトランザクションオブジェクトの配列。</ResponseField>
    <ResponseField name="uncles" type="array">Base では常に `[]`。</ResponseField>
    <ResponseField name="withdrawals" type="array">Base では常に `[]`。</ResponseField>
    <ResponseField name="withdrawalsRoot" type="string">引き出しリストのマークルルート (EIP-4895、bytes32 の16進数) 。</ResponseField>
    <ResponseField name="baseFeePerGas" type="string">EIP-1559 のガスあたりの基本手数料 (16進数) 。</ResponseField>
    <ResponseField name="blobGasUsed" type="string">使用された blob ガスの合計 (EIP-4844、16進数) 。</ResponseField>
    <ResponseField name="excessBlobGas" type="string">blob 手数料の計算に使われる超過 blob ガス (EIP-4844、16進数) 。</ResponseField>
    <ResponseField name="parentBeaconBlockRoot" type="string">親ビーコンブロックのルート (EIP-4788) 。</ResponseField>
    <ResponseField name="requestsHash" type="string">リクエストのハッシュ (EIP-7685) 。</ResponseField>
  </Expandable>
</ResponseField>

## Flashblock固有のレスポンスフィールド {#flashblock-specific-response-fields}

`"pending"` をクエリすると、構築中のブロックのライブスナップショットがレスポンスとして返されます。一部のフィールドは次のように動作が異なります。

| フィールド          | 標準の `latest`      | Flashblocks の `pending`          |
| -------------- | ----------------- | -------------------------------- |
| `number`       | シール済みブロックの番号       | 現在構築中のブロックの番号                    |
| `hash`         | 最終的なブロックハッシュ      | このFlashblockインデックス時点の部分ブロックのハッシュ |
| `gasUsed`      | 最終的なガス使用量         | このFlashblockまでの累積ガス使用量           |
| `transactions` | シール済みのすべてのトランザクション | これまでに事前確認されたトランザクション         |
| `blobGasUsed`  | 最終的なblobガス使用量     | Flashblockの累積状態から引き継がれた値         |

  ```bash 標準（最新のシール済みブロック） lines wrap expandable
  curl https://mainnet.base.org \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{
      "jsonrpc": "2.0",
      "method": "eth_getBlockByNumber",
      "params": ["latest", false],
      "id": 1
    }'
  ```

  ```bash Flashblocks（pending、約200msごとにライブ更新） lines wrap expandable
      "params": ["pending", false],
      "id": 1
    }'
  ```
