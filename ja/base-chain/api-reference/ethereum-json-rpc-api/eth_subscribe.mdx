---
title: 'eth_subscribe'
sidebarTitle: 'eth_subscribe'
description: '新しいブロック、ログ、保留中のトランザクションを対象に、WebSocket によるリアルタイムのサブスクリプションを作成します。'
---

WebSocket 接続を介して、リアルタイムのイベントサブスクリプションを作成します。戻り値はサブスクリプション ID です。イベントは `eth_subscription` 通知としてプッシュされるため、クライアント側でポーリングする必要はありません。

<Note>
  Base の公開エンドポイント (`mainnet.base.org`、`sepolia.base.org`) は **HTTP のみ**に対応しており、WebSocket 接続は利用できません。[Builder Stack](/ja/get-started/builder-stack) から WebSocket に対応したプロバイダーを選択してください。
</Note>

## パラメーター {#parameters}

<ParamField body="subscriptionType" type="string" required>
  サブスクライブするイベントの種類。
</ParamField>

<ParamField body="filterOptions" type="object">
  フィルターオプション (任意) 。サブスクリプションタイプが `"logs"` の場合にのみ適用されます。

  <Expandable title="フィルターオプション（logs のみ）">
    <ParamField body="address" type="string | array">
      フィルタリングに使用するコントラクトアドレス、またはアドレスの配列。任意。
    </ParamField>

    <ParamField body="topics" type="array">
      トピックフィルターの配列。形式は `eth_getLogs` と同じです。任意。
    </ParamField>
  </Expandable>
</ParamField>

## サブスクリプションの種類 {#subscription-types}

| 種類                       | 説明                                  | 通知ペイロード                                                                                                                                          |
| ------------------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `newHeads`               | チェーンに新しいブロックが追加されるたびに発火します          | 完全なブロックヘッダーオブジェクト。`hydrated: false` を指定した [`eth_getBlockByNumber`](/ja/base-chain/api-reference/ethereum-json-rpc-api/eth_getBlockByNumber) と同じ構造です |
| `logs`                   | フィルター条件に一致する新しいログが生成されるたびに発火します     | ログオブジェクト (下記参照)                                                                                                                                  |
| `newPendingTransactions` | メンプールに新しいトランザクションハッシュが追加されるたびに発火します | トランザクションハッシュの文字列                                                                                                                                 |

## 戻り値 {#returns}

<ResponseField name="result" type="string">
  16進数でエンコードされたサブスクリプションID。このサブスクリプションから送られるすべてのイベント通知の `params.subscription` に、このIDが含まれます。
</ResponseField>

イベント通知は、リクエストとは無関係に送られてくるJSON-RPCメッセージとして届きます：

```json Event Notification lines wrap expandable
{
  "jsonrpc": "2.0",
  "method": "eth_subscription",
  "params": {
    "subscription": "0x1887ec8b9589ccad00000000000532da",
    "result": { ... }
  }
}
```
