指定したブロックのすべてのトランザクションレシートを返します。

<Warning>
  このメソッドは、Base の公開 RPC エンドポイント (`mainnet.base.org`、`sepolia.base.org`) では HTTP 403 を返すため、専用またはサードパーティの RPC プロバイダーが必要です。利用可能なプロバイダーについては [Builder Stack](/ja/get-started/builder-stack) を参照してください。
</Warning>

<Tip>
  **Flashblocks:** `https://mainnet.base.org` に `"pending"` を指定してクエリを送信すると、現在の Flashblock に含まれるすべての事前確認済みトランザクションのレシートを取得できます。
</Tip>

## パラメーター {#parameters}

<ParamField body="block" type="string" required>
  16進数表記のブロック番号、または `"latest"`、`"pending"`、`"safe"`、`"finalized"`、`"earliest"` のいずれか。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="array">
  ブロック内の各トランザクションに対応するレシートオブジェクトの配列です。レシートオブジェクトの構造については、[`eth_getTransactionReceipt`](/ja/base-chain/api-reference/ethereum-json-rpc-api/eth_getTransactionReceipt) を参照してください。
</ResponseField>

## 例 {#example}

<CodeGroup>
  ```bash Standard (latest)
  curl https://mainnet.base.org \
    -X POST -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getBlockReceipts","params":["latest"],"id":1}'
  ```

  ```bash Flashblocks (pending)
  curl https://mainnet.base.org \
    -X POST -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","method":"eth_getBlockReceipts","params":["pending"],"id":1}'
  ```

  ```json Response lines wrap expandable

      }

  ```
</CodeGroup>
