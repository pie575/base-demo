---
title: 'debug_traceBlockByHash'
sidebarTitle: 'debug_traceBlockByHash'
description: 'ブロックハッシュで指定したブロック内のすべてのトランザクションについて、EVM の実行トレースを返します。'
---

ハッシュで指定したブロック内のすべてのトランザクションを再実行し、トランザクションごとの実行トレースを返します。

<Warning>
  デバッグメソッドはブロック内のすべてのトランザクションを再実行するため、計算負荷が高くなります。対応状況は [Builder Stack](/ja/get-started/builder-stack) に掲載されているプロバイダーによって異なります。
</Warning>

## パラメーター {#parameters}

<ParamField body="blockHash" type="string" required>
  32バイトのブロックハッシュ。
</ParamField>

<ParamField body="traceOptions" type="object">
  トレース設定 (任意) 。[`debug_traceTransaction`](/ja/base-chain/api-reference/debug-api/debug_traceTransaction) と同じフィールドを指定できます。
</ParamField>

## 戻り値 {#returns}

<ResponseField name="result" type="array">
  トレース結果オブジェクトの配列です。ブロック内の各トランザクションにつき1つのオブジェクトが含まれます。

  <Expandable title="トレース結果のフィールド">
    <ResponseField name="txHash" type="string">トランザクションハッシュ。</ResponseField>
    <ResponseField name="result" type="object">このトランザクションの実行トレース。形式は [`debug_traceTransaction`](/ja/base-chain/api-reference/debug-api/debug_traceTransaction) と同じです。</ResponseField>
  </Expandable>
</ResponseField>
