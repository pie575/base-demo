---
title: "述語と安全性"
description: "有効性述語を安全に使用する方法を説明します。"
---

述語はトランザクションの取り込み条件です。取り込みや実行の成功を保証するものではありません。

## 述語の種類 {#predicate-types}

| 種類                 | パラメータ                                       |
| ------------------ | ------------------------------------------- |
| `balance`          | `address`、`op`、`value`                      |
| `storage`          | `address`、`slot`、`op`、`value`、`mask` (省略可)  |
| `block_number`     | `op`、`value`                                |
| `flashblock_index` | `op`、`value`                                |

サポートされている演算子は `<`、`<=`、`=`、`!=`、`>`、`>=` です。述語の値は、`0x` プレフィックス付きの16進数文字列で指定します。

## 評価 {#evaluation}

Base は、トランザクションの取り込み前にチェックを行います。述語が false の場合、トランザクションは保留状態のままとなります。

先行するトランザクションによって、保留中のトランザクションが監視している残高やストレージ値が変化することがあります。その結果、保留中のトランザクションが同じ Flashblock 内で取り込み可能になる場合があります。

## 残高取得の例 {#balance-example}

```json Balance predicate lines wrap expandable
{
  "type": "balance",
  "params": {
    "address": "0x2222222222222222222222222222222222222222",
    "op": ">=",
    "value": "0x1"
  }
}
```

## ストレージの例 {#storage-example}

```json Storage predicate lines wrap expandable
{
  "type": "storage",
  "params": {
    "address": "0x2222222222222222222222222222222222222222",
    "slot": "0x7",
    "mask": "0xff",
    "op": "=",
    "value": "0x2a"
  }
}
```

Base は `(storage[address][slot] & mask)` と `value` を比較します。ストレージワード全体を比較するには、`mask` を省略してください。

## ブロックと Flashblock の位置 {#block-and-flashblock-position}

ブロックを指定するには `block_number` を、その Flashblock 内の位置を指定するには `flashblock_index` を使用します。両方の条件を満たす必要がある場合は、それぞれ個別の述語を追加してください。

## 安全性 {#safety}

述語はトランザクションをシミュレートするものではありません。重要なチェックは引き続きアプリケーション側の呼び出しで行ってください。

述語は生のストレージを読み取ります。view 関数を呼び出したり、計算によって得られる値を評価したりすることはできません。ストレージ述語を使用する前に、対象コントラクトのストレージレイアウトを確認してください。

状態はブロック構築中に変化する可能性があります。そのため、条件はブロックに取り込まれるまでの間に真にも偽にも変わり得ます。

トランザクションの配置位置を乱数源として使用しないでください。また、スロットの値がゼロであることを根拠に、CREATE2 アドレス、プロキシ、または未初期化のコントラクトを安全に呼び出せると判断しないでください。

有効性の条件はオンチェーンに記録されません。calldata や述語の値に機密情報を含めないでください。
