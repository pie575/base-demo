## プリコンパイルのアドレス {#precompile-addresses}

*Base のシングルトンプリコンパイルの固定アドレスです。詳細は [`StdPrecompiles`](https://github.com/base/base-std/blob/main/src/StdPrecompiles.sol) を参照してください。*

| 名前                            | 値                                            | 用途                                                                                                                                            |
| ----------------------------- | -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `B20_FACTORY_ADDRESS`         | `0xB20f000000000000000000000000000000000000` | B-20 トークンのデプロイと検索を行います。アセットおよびステーブルコインのインスタンスはすべて、このアドレスにある [`IB20Factory`](/ja/specifications/b20/reference/interfaces#ib20factory) を通じて作成されます。 |
| `POLICY_REGISTRY_ADDRESS`     | `0x8453000000000000000000000000000000000002` | 許可リスト/ブロックリスト/複合ポリシーを保存し、各ポリシースコープから参照される `isAuthorized` チェックに応答します ([ポリシー](/ja/specifications/b20/concepts/policies)を参照) 。                      |
| `ACTIVATION_REGISTRY_ADDRESS` | `0x8453000000000000000000000000000000000001` | 特定のチェーン上で B-20 のバリアントや機能が有効化されているかどうかを制御します。ファクトリーは、該当するバリアントを作成する前にこのレジストリを確認します。                                                            |

## 機能および検証の境界値 {#feature-and-validation-bounds}

*一時停止機能と B20Asset 作成時の検証に使用されるビットマスクと、境界値 (いずれもその値を含む) です。[`B20Constants`](https://github.com/base/base-std/blob/main/src/lib/B20Constants.sol) を参照してください。*

| 名前                    | 値                   | 目的                                                                                                      |
| --------------------- | ------------------- | ------------------------------------------------------------------------------------------------------- |
| `ALL_FEATURES_PAUSED` | `15` (`0b1111`)     | すべての `PausableFeature` ビットがセットされたビットマスク (`TRANSFER \| MINT \| BURN \| SEIZE`) 。                         |
| `MIN_ASSET_DECIMALS`  | `6`                 | `B20AssetCreateParams.decimals` の下限 (この値を含む) 。ステーブルコイン水準のインテグレーションの多くが想定する最小値です。                        |
| `MAX_ASSET_DECIMALS`  | `18`                | `B20AssetCreateParams.decimals` の上限 (この値を含む) 。一般的なウォレットやインデクサーであれば正しく表示できる、ERC-20 コミュニティで慣例となっている上限値です。 |
| `MAX_SUPPLY_CAP`      | `type(uint128).max` | 供給上限 (ひいては `totalSupply`) の上限 (この値を含む) 。上限なし (「キャップなし」) を表す番兵値も兼ねます。                                    |

## アセットバリアントの精度定数 {#asset-variant-precision-constants}

*乗数/リベース関連の機能で使用される固定小数点定数です。詳細は [`IB20Asset`](/ja/specifications/b20/reference/interfaces#ib20asset) を参照してください。*

| 名前                  | 値                   | 用途                                                                                                                                            |
| ------------------- | ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `WAD_PRECISION`     | `1e18`              | `multiplier` のスケーリングに使用される固定小数点精度です。`multiplier`、`toUIAmount`、`fromUIAmount` はいずれもこの値で除算/乗算を行います。                                             |
| `MAX_UI_MULTIPLIER` | `type(uint128).max` | セッターが受け付ける乗数の最大値です。`updateMultiplier` および `updateUIMultiplier` が適用するオーバーフロー防止の上限にあたります。呼び出し元が `InvalidMultiplier` を発生させずに上限値を参照できるよう公開されています。 |
