*B20 システムが発行するすべてのイベントを、宣言元のファイルごとにまとめた一覧です。*

## [`IB20`](/specifications/b20/reference/interfaces/ib20) {#ib20}

| イベント                                                                                                      | 発行元                                                                                                                                                    | 発行タイミング                                                                                                                      |
| --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `Transfer(address indexed from, address indexed to, uint256 amount)`                                      | `transfer`, `transferFrom`, `transferWithMemo`, `transferFromWithMemo`, `mint`, `mintWithMemo`, `burn`, `burnWithMemo`, `burnBlocked`, `seizeWithMemo` | 転送、ミント (`from = address(0)`) 、バーン (`to = address(0)`) が成功するたびに発行されます。メモ付き、ブロック済みアカウントのバーン、差し押さえの各バリアントも対象です。                 |
| `Approval(address indexed owner, address indexed spender, uint256 amount)`                                | `approve`, `permit`                                                                                                                                    | アローワンスが設定されたとき。                                                                                                              |
| `Memo(address indexed caller, bytes32 indexed memo)`                                                      | `transferWithMemo`, `transferFromWithMemo`, `mintWithMemo`, `burnWithMemo`                                                                             | 対応する `Transfer` イベントの直後。`caller` はメモ付き呼び出しの `msg.sender` です。                                                                 |
| `BurnedBlocked(address indexed caller, address indexed from, uint256 amount)`                             | `burnBlocked` (非推奨)                                                                                                                                    | `Transfer(from, address(0), amount)` に加えて発行されます。                                                                             |
| `Seized(address indexed caller, address indexed from, address indexed to, uint256 amount)`                | `seizeWithMemo`                                                                                                                                        | `Transfer(from, to, amount)` および `Memo(caller, memo)` に加えて発行されます。転送による差し押さえを記録します。                                           |
| `RoleGranted(bytes32 indexed role, address indexed account, address indexed sender)`                      | `grantRole`                                                                                                                                            | `account` に `role` が付与されたとき。`sender` は呼び出し元です。                                                                               |
| `RoleRevoked(bytes32 indexed role, address indexed account, address indexed sender)`                      | `revokeRole`, `renounceRole`, `renounceLastAdmin`                                                                                                      | `account` から `role` が取り消されたとき。`sender` は管理者ロールの保有者 (`revokeRole`) 、または `account` 自身 (`renounceRole`/`renounceLastAdmin`) です。 |
| `RoleAdminChanged(bytes32 indexed role, bytes32 indexed previousAdminRole, bytes32 indexed newAdminRole)` | `setRoleAdmin`                                                                                                                                         | `role` の管理者ロールが変更されたとき。                                                                                                      |
| `LastAdminRenounced(address indexed previousAdmin)`                                                       | `renounceLastAdmin`                                                                                                                                    | 標準の `RoleRevoked(DEFAULT_ADMIN_ROLE, previousAdmin, previousAdmin)` イベントに加えて発行されます。                                          |
| `Paused(address indexed updater, PausableFeature[] features)`                                             | `pause`                                                                                                                                                | `features` は呼び出し時の引数です (呼び出し後の一時停止状態ではありません) 。                                                                               |
| `Unpaused(address indexed updater, PausableFeature[] features)`                                           | `unpause`                                                                                                                                              | `features` は呼び出し時の引数です (呼び出し後の一時停止状態ではありません) 。                                                                               |
| `PolicyUpdated(bytes32 indexed policyScope, uint64 oldPolicyId, uint64 newPolicyId)`                      | `updatePolicy`、およびトークン作成時                                                                                                                              | トークンのポリシースロットが変更されたとき。作成時の初期スロット割り当てでも、`oldPolicyId == 0` としてこのイベントが発行されます。                                                  |
| `SupplyCapUpdated(address indexed updater, uint256 oldSupplyCap, uint256 newSupplyCap)`                   | `updateSupplyCap`                                                                                                                                      | 供給上限が変更されたとき。                                                                                                                |
| `ContractURIUpdated()`                                                                                    | `updateContractURI`                                                                                                                                    | ERC-7572 に従いパラメーターはありません。インテグレーターは `contractURI()` を再取得します。                                                                  |
| `NameUpdated(address indexed updater, string newName)`                                                    | `updateName`                                                                                                                                           | トークン名が変更されたとき。新しい名前の文字列を含みます。                                                                                                |
| `SymbolUpdated(address indexed updater, string newSymbol)`                                                | `updateSymbol`                                                                                                                                         | トークンシンボルが変更されたとき。新しいシンボルの文字列を含みます。                                                                                           |
| `EIP712DomainChanged()`                                                                                   | `updateName`                                                                                                                                           | ERC-5267 のドメイン変更シグナルです。呼び出しが成功するたびに、`NameUpdated` の直後に必ず 1 回だけ発行されます。`updateSymbol` はこのイベントを発行しません。                          |

## [`IB20Asset`](/specifications/b20/reference/interfaces/ib20-asset) {#ib20asset}

| イベント                                                                                     | 発行元                                             | 発行タイミング                                                                                      |
| ---------------------------------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------------------------------------------------------------- |
| `MultiplierUpdated(uint256 multiplier)`                                                  | `updateMultiplier`(非推奨の即時セッター)                  | 非推奨のレガシートピック向けミラーです。旧トピックを監視するインデクサーが引き続き動作するよう、`UIMultiplierUpdated` と併せて発行されます。[^1]        |
| `UIMultiplierUpdateCancelled(uint256 cancelledMultiplier, uint256 cancelledEffectiveAt)` | `cancelUIMultiplierUpdate`、`updateUIMultiplier` | スケジュール済みの乗数更新がキャンセルされたとき。明示的なキャンセルに加え、`updateUIMultiplier` が有効な保留中の更新をクリアした際の暗黙的なキャンセルも含みます。 |
| `ExtraMetadataUpdated(string key, string value)`                                         | `updateExtraMetadata`                           | 追加メタデータのエントリが設定、更新、または削除されたとき(`value` が空の場合は削除を示します)。                                        |
| `Announcement(address indexed caller, string id, string description, string uri)`        | `announce`                                      | アナウンスメント区間を開始します。                                                                            |
| `EndAnnouncement(string id)`                                                             | `announce`                                      | 同じ `id` を持つ対の `Announcement` で開始された区間を終了します。                                                 |

[^1]: 関数レベルのドキュメントでは、`MultiplierUpdated` を発行するのは `updateMultiplier` のみとされており、スケジュール型の `updateUIMultiplier` が発行するのは `UIMultiplierUpdated` だけです。一方、ソース内のイベント自体のドキュメントコメントでは `updateUIMultiplier` も `MultiplierUpdated` の発行元として記載されており、`updateUIMultiplier` 自身の `@notice` と矛盾しています。どちらか一方を断りなく採用するのではなく、ここで明記しておきます。

## [`IB20Factory`](/specifications/b20/reference/interfaces/ib20-factory) {#ib20factory}

| イベント                                                                                                                                  | 発行元         | タイミング                                                                                                                                                                                   |
| ------------------------------------------------------------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `B20Created(address indexed token, B20Variant indexed variant, string name, string symbol, uint8 decimals, bytes variantEventParams)` | `createB20` | 呼び出しごとに1回、トークンのアイデンティティが確定した後、`initCalls` がディスパッチされる前に発行されます。`variantEventParams` には、バリアント固有のアイデンティティデータが格納されます (ASSET の場合は空、STABLECOIN の場合は ABI エンコードされた `B20StablecoinEventParams`) 。 |

## [`IPolicyRegistry`](/specifications/b20/reference/interfaces/i-policy-registry) {#ipolicyregistry}

| イベント                                                                                                     | 発行元                                                               | 発行タイミング                                                                                            |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| `PolicyCreated(uint64 indexed policyId, address indexed creator, PolicyType policyType)`                 | `createPolicy`、`createPolicyWithAccounts`、`createCompositePolicy` | 新しいポリシーが作成されたとき。                                                                                   |
| `PolicyAdminStaged(uint64 indexed policyId, address indexed currentAdmin, address indexed pendingAdmin)` | `stageUpdateAdmin`                                                | 新しい管理者がステージングされたとき。`pendingAdmin == address(0)` の場合は、既存の指名が取り消されます。                                |
| `PolicyAdminUpdated(uint64 indexed policyId, address indexed previousAdmin, address indexed newAdmin)`   | `finalizeUpdateAdmin`、`renounceAdmin`、およびポリシー作成時                  | 現在の管理者が変更されたとき。`newAdmin == address(0)` は管理者権限の放棄を、`previousAdmin == address(0)` は作成時の初期割り当てを示します。 |
| `AllowlistUpdated(uint64 indexed policyId, address indexed updater, bool allowed, address[] accounts)`   | `updateAllowlist`                                                 | 1 つ以上のアカウントの ALLOWLIST メンバーシップが、1 回のバッチで `allowed` に設定されたとき。                                       |
| `BlocklistUpdated(uint64 indexed policyId, address indexed updater, bool blocked, address[] accounts)`   | `updateBlocklist`                                                 | 1 つ以上のアカウントの BLOCKLIST メンバーシップが、1 回のバッチで `blocked` に設定されたとき。                                       |
| `CompositePolicyUpdated(uint64 indexed policyId, address indexed updater, uint64[] childPolicyIds)`      | `createCompositePolicy`、`updateComposite`                         | 複合ポリシーの子セットが設定されたとき、または全体が置き換えられたとき。作成時とその後の更新のたびに発行され、更新後の子セット全体を含みます。                            |

## [`IActivationRegistry`](/specifications/b20/reference/interfaces/i-activation-registry) {#iactivationregistry}

| イベント                                                                  | 発行元          | 発行タイミング              |
| --------------------------------------------------------------------- | ------------ | -------------------- |
| `FeatureActivated(bytes32 indexed feature, address indexed caller)`   | `activate`   | `feature` が有効化されたとき。 |
| `FeatureDeactivated(bytes32 indexed feature, address indexed caller)` | `deactivate` | `feature` が無効化されたとき。 |

## [`IERC8056`](https://github.com/base/base-std/blob/main/src/interfaces/IERC8056.sol) (`IScaledUIAmount`) {#ierc8056-iscaleduiamount}

| イベント                                                                                              | 発行元                                                          | 発行タイミング                                                                               |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| `UIMultiplierUpdated(uint256 oldMultiplier, uint256 newMultiplier, uint256 effectiveAtTimestamp)` | `updateUIMultiplier` (予約型) 、`updateMultiplier` (非推奨の即時セッター)  | UI 乗数が更新されたとき。予約型のセッターはこのイベントのみを発行し、非推奨の即時セッターは `MultiplierUpdated` と併せてこのイベントを発行します。 |
