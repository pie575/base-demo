## 我该使用哪个接口？ {#which-surface-do-i-need}

| 你想要…               | 使用                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------- |
| 验证账户所有权或执行身份策略     | [Base Verify API](/zh/sdks/base-verify/overview)                                         |
| 在本地构建和测试 Base 原生合约 | [base-anvil CLI](/zh/sdks/base-anvil)                                                    |
| 读取余额、区块、日志或发送原始交易  | [Ethereum JSON-RPC](/zh/base-chain/api-reference/rpc-overview)                           |
| 以流式方式获取亚秒级确认       | [Flashblocks API](/zh/base-chain/api-reference/flashblocks-api/flashblocks-api-overview) |
| 追踪交易或区块            | [Debug API](/zh/base-chain/api-reference/debug-api/debug_traceTransaction)               |
