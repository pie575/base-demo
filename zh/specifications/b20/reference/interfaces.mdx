B20 接口定义了代币、工厂和注册表这几个预编译合约对外暴露的接口。各函数的具体行为请参阅链接的参考文档。官方 Solidity 文件位于 [`base-std`](https://github.com/base/base-std/tree/main/src/interfaces) 中。

| `IB20Asset`           | [IB20Asset 参考文档](/specifications/b20/reference/interfaces/ib20-asset)                      | [IB20Asset.sol](https://github.com/base/base-std/blob/main/src/interfaces/IB20Asset.sol)                     |

## 可直接复制的导入语句 {#copy-and-paste-imports}

以下导入语句需配合 Foundry 重映射 `base-std/=src/` 使用。

### IB20 {#ib20}

```solidity filename="IB20.sol"
import {IB20} from "base-std/interfaces/IB20.sol";
```

### IB20Asset {#ib20asset}

```solidity filename="IB20Asset.sol"
import {IB20Asset} from "base-std/interfaces/IB20Asset.sol";
```

### IB20Stablecoin {#ib20stablecoin}

```solidity filename="IB20Stablecoin.sol"
import {IB20Stablecoin} from "base-std/interfaces/IB20Stablecoin.sol";
```

### IB20Factory {#ib20factory}

```solidity filename="IB20Factory.sol"
import {IB20Factory} from "base-std/interfaces/IB20Factory.sol";
```

### IPolicyRegistry {#ipolicyregistry}

```solidity filename="IPolicyRegistry.sol"
import {IPolicyRegistry} from "base-std/interfaces/IPolicyRegistry.sol";
```

### IActivationRegistry {#iactivationregistry}

```solidity filename="IActivationRegistry.sol"
import {IActivationRegistry} from "base-std/interfaces/IActivationRegistry.sol";
```

### IERC8056 {#ierc8056}

```solidity filename="IERC8056.sol"
import {
    IScaledUIAmount,
    IScaledUIAmountBalances,
    IScaledUIAmountConversion,
    IScaledUIAmountNewUIMultiplier
} from "base-std/interfaces/IERC8056.sol";
```

### IERC165 {#ierc165}

```solidity filename="IERC165.sol"
import {IERC165} from "base-std/interfaces/IERC165.sol";
```

标准的预编译合约地址请参阅 [`StdPrecompiles`](https://github.com/base/base-std/blob/main/src/StdPrecompiles.sol)。
