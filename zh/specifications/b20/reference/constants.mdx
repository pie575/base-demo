## 预编译合约地址 {#precompile-addresses}

*Base 单例预编译合约的固定地址。参见 [`StdPrecompiles`](https://github.com/base/base-std/blob/main/src/StdPrecompiles.sol)。*

| 名称                            | 值                                            | 用途                                                                                                             |
| ----------------------------- | -------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| `B20_FACTORY_ADDRESS`         | `0xB20f000000000000000000000000000000000000` | 用于部署和查找 B-20 代币；所有资产代币和稳定币实例均通过该地址上的 [`IB20Factory`](/zh/specifications/b20/reference/interfaces#ib20factory) 创建。 |
| `POLICY_REGISTRY_ADDRESS`     | `0x8453000000000000000000000000000000000002` | 存储允许列表、阻止列表及组合策略，并响应所有策略作用域发起的 `isAuthorized` 检查 (参见[策略](/zh/specifications/b20/concepts/policies)) 。             |
| `ACTIVATION_REGISTRY_ADDRESS` | `0x8453000000000000000000000000000000000001` | 控制某个 B-20 变体或功能是否已在特定链上启用；工厂在创建该变体前会先查询此处。                                                                     |

## 功能与校验边界 {#feature-and-validation-bounds}

*用于暂停功能和 B20Asset 创建校验的位掩码及闭区间边界。参见 [`B20Constants`](https://github.com/base/base-std/blob/main/src/lib/B20Constants.sol)。*

| 名称                    | 值                   | 用途                                                                          |
| --------------------- | ------------------- | --------------------------------------------------------------------------- |
| `ALL_FEATURES_PAUSED` | `15` (`0b1111`)     | 所有 `PausableFeature` 位均已置位的位掩码 (`TRANSFER \| MINT \| BURN \| SEIZE`) 。      |
| `MIN_ASSET_DECIMALS`  | `6`                 | `B20AssetCreateParams.decimals` 的下界 (含) ；即大多数稳定币级集成所要求的最低精度。                |
| `MAX_ASSET_DECIMALS`  | `18`                | `B20AssetCreateParams.decimals` 的上界 (含) ；即 ERC-20 社区公认的上限，所有常见钱包/索引器均能正确显示。 |
| `MAX_SUPPLY_CAP`      | `type(uint128).max` | 供应上限 (进而也是 `totalSupply`) 的上界 (含) ；同时用作表示“无上限”的哨兵值。                         |

## 资产变体精度常量 {#asset-variant-precision-constants}

*乘数/变基相关接口所使用的定点常量。参见 [`IB20Asset`](/zh/specifications/b20/reference/interfaces#ib20asset)。*

| 名称                  | 值                   | 用途                                                                                                                   |
| ------------------- | ------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `WAD_PRECISION`     | `1e18`              | 用于缩放 `multiplier` 的定点精度；`multiplier`、`toUIAmount` 和 `fromUIAmount` 均以此值作为除数/乘数。                                      |
| `MAX_UI_MULTIPLIER` | `type(uint128).max` | 设置函数所能接受的最大乘数，即 `updateMultiplier` 和 `updateUIMultiplier` 强制执行的溢出保护上限。公开此常量，是为了让调用方无需触发 `InvalidMultiplier` 即可读取该上限。 |
