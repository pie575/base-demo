Base 的配置分为以下四类：

* **共识参数 (Consensus Parameters)&#x20;**：在创世时固定，或可通过特权账户或协议升级进行更改。
* **策略参数 (Policy Parameters)&#x20;**：可在协议规定的约束范围内更改，不会破坏共识。
* **管理员角色 (Admin Roles)&#x20;**：可升级合约、变更角色所有者或更新协议参数的账户，通常为冷钱包或多签钱包。
* **服务角色 (Service Roles)&#x20;**：用于日常运营的账户，通常为热钱包。

## 策略参数 {#policy-parameters}

| 参数                                                                       | 描述                                                                                                                         | 管理者                      |
| ------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------- | ------------------------ |
| [数据可用性类型](/zh/specifications/reference/glossary#data-availability-provider) | batcher 以 blob 还是 calldata 形式发布数据。Ethereum (Blobs 或 Calldata) ；不支持 Alt-DA。                                                 | [Batch Submitter](#service-roles)  |
| 批次提交频率                                                                   | 向 L1 提交 [batcher 交易](/zh/specifications/reference/glossary#batcher-transaction)的频率。≤ 1,800 个 L1 区块 (按 L1 出块时间 12 秒计，即 6 小时) 。 | [Batch Submitter](#service-roles)  |
| 输出频率                                                                     | 向 L1 提交输出根的频率。≤ 43,200 个 L2 区块 (按 L2 出块时间 2 秒计，即 24 小时) ；不得为零。启用故障证明后弃用。                                                   | [L1 Proxy Admin](#admin-roles) |
