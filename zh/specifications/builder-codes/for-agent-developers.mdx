AI 智能体可自主运行并发送交易，无需用户逐笔手动触发。借助 Builder Codes，您可以将这些活动全部归因到智能体在 Base 上的身份。

## 为什么智能体需要 Builder Codes {#why-agents-need-builder-codes}

* **归因** — 你的智能体发送的每一笔交易都会关联到你在 Base 注册表中的身份。没有 Builder Codes，你的智能体的链上活动就是匿名的。
* **数据分析** — 在 [base.dev](https://base.dev) 中追踪智能体的交易量、用户覆盖面和链上转化情况。
* **曝光度** — 拥有 Builder Codes 的智能体有机会出现在 Base 应用排行榜 (App Leaderboard) 、生态系统焦点推荐等发现渠道中。

## 工作原理 {#how-it-works}

Builder Code 是一个唯一标识符 (例如 `bc_a1b2c3d4`) ，会以 [ERC-8021](https://eip.tools/eip/8021) 后缀的形式附加到你的智能体交易的 calldata 末尾。智能合约会忽略该后缀，之后再由链下索引器将其提取出来。额外的 gas 开销极小 (每个非零字节 16 gas) 。

## API 参考 {#api-reference}

### 注册智能体 {#register-your-agent}

```http Register an agent Builder Code
POST /v1/agents/builder-codes
```

无需身份验证。

| 字段              | 类型     | 必填 | 描述                         |
| --------------- | ------ | -- | -------------------------- |
| `walletAddress` | string | 是  | 你的智能体的 EVM 钱包地址 (`0x...`)  |

返回指定钱包对应的 builder code。同一钱包地址始终返回相同的 code。

```bash Terminal
curl -X POST https://api.base.dev/v1/agents/builder-codes \
  -H "Content-Type: application/json" \
  -d '{
    "walletAddress": "<your-wallet-address>"
  }'
```

```json Response
{
  "builderCode": "bc_a1b2c3d4",
  "walletAddress": "0x..."
}
```

<Info>
  已经注册过？使用相同的钱包地址再次调用此端点，会返回你现有的 builder code。因此，每次部署时都可以放心调用。
</Info>

## 使用 Base 技能 {#using-the-base-skill}

如果你在使用 AI 编程工具 (Claude Code、Cursor、Codex) ，请安装 Base 技能包，由该技能全程自动完成注册：

```bash Terminal
npx skills add base/base-skills
```

然后对你的智能体说：**&quot;Register my agent for a builder code on Base.dev.&quot;**

该技能会自动完成以下操作：验证钱包、调用注册 API、将返回的代码写入 `src/constants/builderCode.ts`、安装 `ox`，并将 ERC-8021 `dataSuffix` 接入你的交易客户端 (viem、ethers.js 或托管服务) 。

## 验证归因 {#verify-attribution}

要确认你的 Builder Code 是否已正确附加：

**1. 在 base.dev 上查看**

* 访问 [base.dev](https://base.dev)
* 在交易类型下拉菜单中选择 **Onchain**
* 在 Total Transactions 部分，每当包含你的代码的交易被处理，归因计数就会相应增加

**2. 使用区块浏览器 (Basescan、Etherscan 等)&#x20;**

* 找到你的交易哈希
* 查看输入数据 (input data) 字段
* 确认最后 16 个字节为重复的 `8021`
* 解码该后缀，确认其中包含你的 Builder Code

**3. 使用开源工具**

* 打开 [Builder Code Validation](https://builder-code-checker.vercel.app/) 工具
* 选择交易类型
* 输入交易哈希或 UserOperation 哈希
* 点击 **Check Attribution** 按钮
