要让你的应用被视为值得信赖、不被标记为恶意，就需要遵循最佳实践。以下简明指南将帮助你从一开始就构建安全、合规的应用。

## 1. 验证智能合约并降低其风险 {#1-verify-and-reduce-the-risk-of-your-smart-contract}

* **验证智能合约**：确保你的合约源代码已通过 [Builder Stack](/zh/get-started/builder-stack) 中列出的区块浏览器完成验证并公开可查。例如，你可以在 [Etherscan](https://etherscan.io/verifyContract) 或 [Basescan](https://basescan.org/verifyContract) 的“Verify Contract”页面验证合约。
* **限制用户资金的风险敞口**：设计合约时，应尽量降低用户资金的风险敞口。通过高效的设计规避一切不必要的风险，例如仅请求完成交易所需的最低金额。

## 2. 提交验证请求 {#2-submit-a-verification-request}

完成智能合约验证后，建议[提交验证请求](https://report.blockaid.io/)。这一步有助于让你的应用获得生态系统中可信机构的认可，被认定为安全且已验证。

## 3. 遵循应用最佳实践 {#3-follow-app-best-practices}

* **跨地区可访问性**：避免使用地理封锁或访问限制，以免特定地区或国家的用户无法访问你的应用。如因法律或合规原因确需设置此类限制，可在提交验证请求时予以说明。
* **行为一致**：避免 UI 出现频繁或无故的变化，以免用户对应用的可靠性产生疑虑。
* **透明的链上交互**：确保应用的链上交互清晰明确，并与 UI 操作保持一致。例如，“Mint”按钮就应明确发起一笔铸造交易。
* **标准登录方式**：提供所有标准的连接方式供用户登录，例如 WalletConnect / Coinbase Wallet SDK 或主流浏览器扩展钱包。
* **审计你的合约**：请信誉良好的机构审计你的合约。公开审计报告并提供链接，方便用户查阅。审计能够表明你已采取额外措施保障智能合约的安全。

遵循这些建议，可以显著降低应用被标记为恶意的可能性，并为用户营造安全可信的环境。

***

**仍有问题？**
Coinbase Wallet 在标记应用时可能出现误报。为避免误报，请确保已完成上述建议操作。如果你的应用仍被标记为可疑或恶意，请[向 Blockaid 报告](https://report.blockaid.io/mistake)。
