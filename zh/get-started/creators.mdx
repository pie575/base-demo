## 创作者资助计划 {#creator-grant-program}

我们将为已在围绕 Base 持续产出优质内容的独立创作者提供最高 $4,000 的资助，涵盖以下类别：

1. 撰写 Base 相关内容的作者 (深度解析、梗图、分析、推文长帖) 
2. 主播和直播节目主持人
3. 定期更新播客或节目的创作者
4. 独立视频创作者
5. 用自己的母语讲解 Base 的教育者
