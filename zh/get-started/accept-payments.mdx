在 Base 上收款，并按产品需求选择合适的支付生命周期。借助 [Commerce Payments Protocol](https://github.com/base/commerce-payments)，你可以立即扣款，也可以在履约前将资金预留至托管账户，随后在付款方批准的条款范围内进行请款 (capture) 、作废 (void) 、收回 (reclaim) 或退款 (refund) 。此解决方案还涵盖定期收款、对账、付款发放、分账以及 x402 API。

## 支付生命周期 {#payment-lifecycle}

| 阶段              | 具体过程                        | 入门指南                                                               |
| --------------- | --------------------------- | ------------------------------------------------------------------ |
| 收款 (Charge)     | 运营方以原子方式完成一笔协议支付的收取与结算      | [发起支付请求](/zh/build-on-base/accept-payments/request-a-payment)         |
| 授权 (Authorize)  | 运营方将付款方资金转入托管               | [授权支付](/zh/build-on-base/accept-payments/authorize-a-payment)         |
| 请款 (Capture)    | 运营方结算全部或部分托管金额              | [对授权进行请款](/zh/build-on-base/accept-payments/capture-an-authorization) |
| 确认 (Confirm)    | 你的后端验证已确认的协议事件，并确保每笔订单只认领一次 | [验证支付](/zh/build-on-base/accept-payments/verify-a-payment)            |
| 退款或分账           | 你向付款方退款，或向下游收款方付款           | [退款](/zh/build-on-base/accept-payments/refund-a-payment)              |
