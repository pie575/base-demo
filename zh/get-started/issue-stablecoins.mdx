使用 Base 的原生代币标准 [B20](/zh/specifications/b20)，即可在 Base 上发行法币支持的稳定币。铸造、赎回、合规控制和对账功能均已内置于链上，无需自行开发或审计定制合约，且完全兼容 ERC-20。
