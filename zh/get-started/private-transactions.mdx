借助 **Base Ledgers**，您可以在 Base 上运行自己的私密支付产品。余额、转账和交易对手信息不会出现在公共区块浏览器上，而资金则通过单一的 `Portal` 合约在 Base 上结算。合规性由您自己的 KYC 控制措施在账本层面强制执行；资金以自托管方式存放在您控制的合约中；每笔存款和提款都是一次链上调用，可以与其他 Base 操作原子化地打包执行。

## 为什么选择 Base Ledgers {#why-base-ledgers}

* **默认私密。** 余额、交易和转账都不会显示在公共区块浏览器上。存款会隐藏接收方，提款会隐藏发送方，因此二者无法关联。
* **合规。** 运营方通过自身的 KYC 和合规管控机制控制账本的准入。
* **可与 Base 组合。** 存款和提款均为链上调用，你可以将其与其他操作打包 (如&quot;存款后执行操作&quot;或&quot;提款后兑换&quot;) ，这些操作要么一并结算，要么全部不执行。
* **可配置。** 按你自己的规则运行账本：资金自行托管，交易处理逻辑也可自定义。

## 工作原理 {#how-it-works}

一笔支付会经历三个阶段：资金通过 Portal 合约进入账本，在账本内私密流转，最后退出并返回 Base。运营方负责运行处理各个环节的服务，并决定如何授权提款。

1. **[存款](/zh/build-on-base/ledgers/deposit)。** 用户将资金从 Base 转入账本。接收方信息经过加密，因此存入同一账户的多笔存款之间无法相互关联。
2. **[账本内转账](/zh/build-on-base/ledgers/transfer)。** 在账本内，用户可以转账、兑换和赚取收益，余额和活动记录始终保持私密。
3. **[提款](/zh/build-on-base/ledgers/withdraw)。** 用户将资金转回 Base。提款在链上会公开资产和金额，但不会暴露其背后的账户。
