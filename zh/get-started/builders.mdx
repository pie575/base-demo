## 构建 {#build}

### 文档 {#documentation}

了解[基础知识](/zh/get-started/base)，助你快速上手链上开发。

### Builder Codes {#builder-codes}

Base 团队对资助的审核非常严格。要获得资助资格，第一步是集成 Builder Codes。

Builder Codes 是一种唯一标识符，用于标记你的应用发起的交易，使 Base 能够将链上活动归属于你。我们希望确保你已完成相关设置。

<a className="view-features-btn button-white" href="/zh/specifications/builder-codes/overview">了解更多</a>

### Quests {#quests}

想找个实际问题来检验所学吗？

Builder Quests 是 Base 面向构建者社区定期发起的挑战活动：选定一个主题，围绕它打造真正可用的项目，即可获得奖励。关注 Build on Base 账号，获取最新的 Quest 动态。

<a className="view-features-btn button-white" href="https://x.com/buildonbase">了解更多</a>

## 支持 {#support}

### Builder Stack {#builder-stack}

Builder Stack 将这些资源整合打包，提供一个涵盖 LLM 推理、云服务及其他开发基础设施的工具与额度资源池。团队一旦入选 Builder Grant Program，即可解锁使用。

<a className="view-features-btn button-white" href="/zh/get-started/base-services-hub">了解更多</a>

### 区域推广 {#regional-amplification}

如果你正在 Base 上积极构建，并且已经取得一定成绩，我们很乐意在推广方面为你提供支持。

请阅读我们的推广[指南](https://github.com/base-org/brand-kit/blob/main/guides/editorial-style-guide.md#what-to-avoid)，了解最佳实践。

如果你即将发布新产品、新功能或重大版本，我们将通过 Base 各区域社区账号帮你宣传。这些账号覆盖拉丁美洲、亚太、欧洲、非洲、印度和巴西，社区成员合计超过 10 万人。

<a className="view-features-btn button-white" href="https://forms.gle/q852YTA83eUTFyz37">申请</a>

### Baseposting 报道 {#baseposting-coverage}

Baseposting 每日报道 Base 生态系统的最新动态。我们无法保证覆盖每个项目，但如果希望获得报道，最好的方式是在发布重要更新的帖子中标记 [@baseposting](https://x.com/baseposting)。

### Builder Call {#builder-call}

我们每季度举办两次 [Base Builder Call](https://x.com/base/status/2085381551437570256?s=20)，从产品、构建者、社区等多个方面探讨 Base 生态系统的现状。

如果你希望自己的项目在下一期亮相，请在 X 上 @AhaanRaizada，并简要介绍你正在 Base 上构建的项目。

### 圆桌会议 {#roundtables}

每周四美国东部时间下午 1:30，我们会在 X Space 上举办 Builder Roundtable，围绕当周主题展开讨论，并邀请 Base 构建者分享发言。如果你有兴趣参加下一期，请在 X 上私信 @saxenasaheb 或 @AhaanRaizada。

## 获取资助 {#get-funded}

### 资助计划 {#grant-program}

在 Base 上积极构建以下方向的项目，即可获得最高 5,000 美元的资助，以及市场推广 (GTM) 和产品支持：

1. 预测市场
2. 代币发行平台
3. DeFi 2.0——借贷、循环借贷、收益生成、金库、代币化股票
4. 智能体——商业、x402 实现、自主交易
5. 专注于新资产创建的产品
6. 专注于交易增长的消费级应用

立即申请，加入我们的下一期计划。

### Base Batches {#base-batches}

Base Batches 是由 Base Ecosystem Fund 运营的加速器项目，面向在 Base 上构建未来金融的早期团队。每期均为短期线上项目，最后以面向投资人的 Demo Day 收官。

<a className="view-features-btn button-white" href="https://www.base.org/batches">立即申请</a>

### Base Ecosystem Fund {#base-ecosystem-fund}

Base Ecosystem Fund 是 Base 的战略投资部门，由 Base 与 Coinbase Ventures 合作运营，专注于支持在 Base 上打造链上业务的早期团队。

<a className="view-features-btn button-white" href="https://www.base.org/ecosystem-fund">申请</a>
