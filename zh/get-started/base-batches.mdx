Base Batches 是由 [Base Ecosystem Fund](/zh/get-started/base-ecosystem-fund) 运营的加速器，面向在 Base 上构建未来金融的早期团队。每期项目均为短期线上形式，最后以面向投资人的路演日收官。如需了解更多信息，请访问[项目页面](https://www.base.org/batches)。

## 你将获得 {#what-you-get}

* Base Ecosystem Fund 提供的 100,000 美元投资。
* 为期 8 周的线上项目，配备专属顾问，每周提供支持。
* 与 Base 生态系统中各领域专家交流的机会。
* 在精选风险投资人面前路演的路演日。

## 适合对象 {#who-its-for}

早期团队，无论尚处于产品成型前，还是已推出 MVP，只要尚未完成正式种子轮融资，并坚定地以 Base 作为主要网络即可。Base Batches 寻找在以下领域进行构建的创始人：

* 交易
* 支付
* 智能体
* 融资
* 资产发行

## 申请 {#apply}

每年开放两期。申请前，请先前往[项目页面](https://www.base.org/batches)查看最新日期。
