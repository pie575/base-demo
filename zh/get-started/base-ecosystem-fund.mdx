Base 生态基金是 Base 的战略投资部门，与 Coinbase Ventures 合作运营，专注于投资在 Base 上构建链上业务的早期团队。详情请访问[基金页面](https://www.base.org/ecosystem-fund)。

## 提供的支持 {#what-it-offers}

* 为在 Base 上构建的团队提供种子前轮和种子轮投资。
* 提供实打实的生态系统支持，并引荐合作伙伴。
* 提供来自 AWS、Azure 和 Alchemy 等服务商的合作伙伴额度。
* 优先获得 Coinbase Prime、Coinbase Business 和入金 (onramp) API 的使用权限。

## 适用对象 {#who-its-for}

处于种子前轮和种子轮阶段的创始人，致力于打造经久不衰的链上基础组件与业务，推动真实的经济活动，涵盖以下领域：

* 交易
* 支付
* AI 智能体
* 其他链上业务
