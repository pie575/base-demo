Base 采用与以太坊相同的交易模型，因此任何 EVM 库都能直接使用。下面是一个使用 [viem](https://viem.sh) 发送交易的最简示例。

## 发送交易 {#send-a-transaction}

```ts send.ts lines wrap expandable
import { createWalletClient, http, parseEther } from 'viem';
import { privateKeyToAccount } from 'viem/accounts';
import { base } from 'viem/chains';

const account = privateKeyToAccount('0xYourPrivateKey');

const client = createWalletClient({
  account,
  chain: base,
  transport: http('https://mainnet.base.org'),
});

const hash = await client.sendTransaction({
  to: '0xRecipientAddress',
  value: parseEther('0.001'),
});

console.log(`Sent, view at https://basescan.org/tx/${hash}`);
```

<Warning>
  切勿硬编码或泄露私钥。`'0xYourPrivateKey'` 仅为占位符。请从环境变量或密钥管理服务中加载私钥，确保其仅保存在服务器端，切勿将其提交到源代码管理系统。
</Warning>

<Tip>
  得益于 [Flashblocks](/zh/specifications/transactions/transaction-ordering#flashblocks)，Base 上的交易可在一秒内完成确认，gas 费用通常不到一美分。
</Tip>
