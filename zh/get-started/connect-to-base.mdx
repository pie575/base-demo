Base 是一条标准的 EVM 链，因此任何以太坊工具、钱包或库都无需修改即可直接使用，只需将其配置为下方的网络信息即可。

## 网络信息 {#network-details}

|        | Base Mainnet                         | Base Sepolia (测试网)                                   |
| ------ | ------------------------------------ | ---------------------------------------------------- |
| RPC 端点 | `https://mainnet.base.org`           | `https://sepolia.base.org`                           |
| 链 ID   | `8453`                               | `84532`                                              |
| 原生代币   | ETH                                  | ETH                                                  |
| 区块浏览器  | [basescan.org](https://basescan.org) | [sepolia.basescan.org](https://sepolia.basescan.org) |
