返回最新区块的区块号。

## 参数 {#parameters}

无参数。

## 返回值 {#returns}

<ResponseField name="result" type="string">
  当前区块号，以十六进制字符串表示。
</ResponseField>

## 示例 {#example}

<CodeGroup>
  ```json Request
  {
    "jsonrpc": "2.0",
    "method": "eth_blockNumber",
    "params": [],
    "id": 1
  }
  ```

  ```json Response
  {
    "jsonrpc": "2.0",
    "id": 1,
    "result": "0x158a0e9"
  }
  ```
</CodeGroup>
