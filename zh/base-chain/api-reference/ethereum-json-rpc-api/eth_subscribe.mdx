---
title: 'eth_subscribe'
sidebarTitle: 'eth_subscribe'
description: '创建实时 WebSocket 订阅，用于接收新区块、日志和待处理交易。'
---

通过 WebSocket 连接创建实时事件订阅。该方法返回一个订阅 ID，之后事件会以 `eth_subscription` 通知的形式主动推送，客户端无需轮询。

<Note>
  Base 公共端点 (`mainnet.base.org`、`sepolia.base.org`) **仅支持 HTTP**，不提供 WebSocket 连接。如需使用 WebSocket，请从 [Builder Stack](/zh/get-started/builder-stack) 中选择支持 WebSocket 的服务商。
</Note>

## 参数 {#parameters}

<ParamField body="subscriptionType" type="string" required>
  要订阅的事件类型。
</ParamField>

<ParamField body="filterOptions" type="object">
  可选的过滤选项，仅适用于 `"logs"` 订阅类型。

  <Expandable title="过滤选项（仅限 logs）">
    <ParamField body="address" type="string | array">
      用于过滤的单个合约地址或地址数组。可选。
    </ParamField>

    <ParamField body="topics" type="array">
      topic 过滤器数组，格式与 `eth_getLogs` 相同。可选。
    </ParamField>
  </Expandable>
</ParamField>

## 订阅类型 {#subscription-types}

| 类型                       | 描述              | 通知负载                                                                                                                                      |
| ------------------------ | --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `newHeads`               | 每有新区块追加到链上时触发   | 完整的区块头对象，结构与 `hydrated: false` 时 [`eth_getBlockByNumber`](/zh/base-chain/api-reference/ethereum-json-rpc-api/eth_getBlockByNumber) 返回的结果完全相同 |
| `logs`                   | 每有符合过滤条件的新日志时触发 | 日志对象 (见下文)                                                                                                                                |
| `newPendingTransactions` | 每有新交易哈希加入内存池时触发 | 交易哈希字符串                                                                                                                                   |

## 返回值 {#returns}

<ResponseField name="result" type="string">
  十六进制编码的订阅 ID。该订阅的所有事件通知都会在 `params.subscription` 中携带此 ID。
</ResponseField>

事件通知以 JSON-RPC 消息的形式主动推送，无需客户端发起请求：

```json Event Notification lines wrap expandable
{
  "jsonrpc": "2.0",
  "method": "eth_subscription",
  "params": {
    "subscription": "0x1887ec8b9589ccad00000000000532da",
    "result": { ... }
  }
}
```
