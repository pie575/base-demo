返回某个地址在指定区块的 ETH 余额。

<Tip>
  **Flashblocks：** 使用 `"pending"` 查询 `https://mainnet.base.org`，即可读取约每 200ms 更新一次的余额，无需等待区块封存。
</Tip>

## 参数 {#parameters}

<ParamField body="address" type="string" required>
  要查询的 20 字节地址。
</ParamField>

<ParamField body="block" type="string" required>
  十六进制格式的区块号，或 `"latest"`、`"pending"`、`"safe"`、`"finalized"`、`"earliest"` 之一。使用 `"pending"` 可查询预确认余额。
</ParamField>

## 返回值 {#returns}

<ResponseField name="result" type="string">
  以十六进制字符串表示的余额，单位为 wei。
</ResponseField>

## 示例 {#example}

<CodeGroup>
  ```bash 标准（latest） lines wrap expandable
  curl https://mainnet.base.org \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{
      "jsonrpc": "2.0",
      "method": "eth_getBalance",
      "params": ["0x742d35Cc6634C0532925a3b8D4C9dD0b4f3BaEa", "latest"],
      "id": 1
    }'
  ```

  ```bash Flashblocks（pending，约 200ms） lines wrap expandable
  curl https://mainnet.base.org \
    -X POST \
    -H "Content-Type: application/json" \
    -d '{
      "jsonrpc": "2.0",
      "method": "eth_getBalance",
      "params": ["0x742d35Cc6634C0532925a3b8D4C9dD0b4f3BaEa", "pending"],
      "id": 1
    }'
  ```

  ```json 响应
  {
    "jsonrpc": "2.0",
    "id": 1,
    "result": "0x1a055690d9db80000"
  }
  ```
</CodeGroup>
