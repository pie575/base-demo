---
title: 'debug_traceBlockByHash'
sidebarTitle: 'debug_traceBlockByHash'
description: '根据区块哈希，返回该区块中所有交易的 EVM 执行追踪。'
---

重放指定哈希对应区块中的所有交易，并返回每笔交易的执行追踪。

<Warning>
  调试方法会重放区块中的所有交易，计算开销较大。[Builder Stack](/zh/get-started/builder-stack) 中各提供商对这些方法的支持情况不尽相同。
</Warning>

## 参数 {#parameters}

<ParamField body="blockHash" type="string" required>
  32 字节的区块哈希。
</ParamField>

<ParamField body="traceOptions" type="object">
  可选的追踪配置，支持的字段与 [`debug_traceTransaction`](/zh/base-chain/api-reference/debug-api/debug_traceTransaction) 相同。
</ParamField>

## 返回值 {#returns}

<ResponseField name="result" type="array">
  由追踪结果对象组成的数组，区块中的每笔交易各对应一个对象。

  <Expandable title="追踪结果字段">
    <ResponseField name="txHash" type="string">交易哈希。</ResponseField>
    <ResponseField name="result" type="object">该交易的执行追踪，格式与 [`debug_traceTransaction`](/zh/base-chain/api-reference/debug-api/debug_traceTransaction) 相同。</ResponseField>
  </Expandable>
</ResponseField>
