如果你需要识别链上活动由哪个构建者产生，或判断用户是否满足经过验证的资格要求，请使用归因功能。Builder Codes 和 Base Verify 分别解决这一问题的不同方面。

## 链上活动归因 {#attribute-onchain-activity}

Builder Codes 会在交易 calldata 末尾附加 ERC-8021 归因后缀。链下索引器借助该后缀，将链上活动与其发起方 (应用、钱包或智能体) 关联起来。

## 验证用户属性 {#verify-user-attributes}

Base Verify 可让用户证明其对受支持账户的控制权，并让你的应用评估已获批准的特征。若体验由应用控制，请选择后端流程；若策略必须由智能合约强制执行，请选择链上流程。

<Note>
  Builder Codes 用于标记交易来源的归属，并不验证用户的身份或资格。Base Verify 用于评估已验证的用户属性，并不会将交易归属到生成该交易的构建者。
</Note>
