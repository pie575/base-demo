资金通过 Base 上的 `Portal` 合约从账本中转出。你可以自行选择 Portal 验证提款的方式 (从简单的签名检查到完整的状态转换证明) ，同时提款背后的账户始终保持私密，因此存款与提款之间无法被关联。详见[私密交易](/zh/get-started/private-transactions)。

## 链上公开哪些数据 {#whats-exposed-onchain}

| 数据  | 是否公开？ | 原因              |
| --- | ----- | --------------- |
| 资产  | 公开    | 在 Base 上结算所必需。  |
| 金额  | 公开    | 在 Base 上结算所必需。  |
| 发送方 | 隐藏    | 账本 Portal 不会披露。 |
| 接收方 | 公开    | 在 Base 上结算所必需。  |

`withdraw()` 是普通的 Base 合约调用，因此你可以将它与其他 Base 操作打包进同一笔原子交易。这些操作要么全部结算，要么全部不结算。
