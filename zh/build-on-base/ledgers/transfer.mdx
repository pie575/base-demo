资金存入账本后，账户即可进行转账、兑换和赚取收益，而余额和活动记录均不会出现在公开的区块浏览器上。只有存款和提款会在 Base 上发生，其间的所有操作均为私密进行。详见[私密交易](/zh/get-started/private-transactions)。

## 链上公开了哪些信息 {#whats-exposed-onchain}

| 数据  | 是否公开？ | 原因                 |
| --- | ----- | ------------------ |
| 发送方 | 隐藏    | 转账始终在账本内部完成。       |
| 接收方 | 隐藏    | 转账始终在账本内部完成。       |
| 金额  | 隐藏    | 转账始终在账本内部完成。       |
| 活动  | 隐藏    | 转账的任何信息都不会写入 Base。 |

账本不依赖于其背后的任何特定链下系统，因此你可以自行记账，并实现自定义交易逻辑。
